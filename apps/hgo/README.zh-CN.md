# HGO 原生地图工坊

HGO 是与主编辑器并行的子项目。它直接使用模组的原始像素地图，独立加载、渲染、保存和测试；海域与陆地的州使用同一套编辑工具。原始实体与核心资料保持只读，项目可编辑当前归属和国家基础色。

## 本地打开

在仓库根目录运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/apps/hgo/`。随附数据足以运行，无需安装或下载原始模组。浏览器需要 WebGL 2，显卡需支持至少 5120×2560 的纹理；完整性校验与 gzip 解码需要 localhost 或 HTTPS。

主编辑器的剧本面板、指南与网站首页均有 HGO 入口。主编辑器可将 schema-1 原生 HGO JSON 转交给独立页面；新 schema-2 文件请直接在 HGO 打开。双方通过限时、一次性项目交接传递旧版文档，不导入彼此的渲染器或状态。

## 编辑

- 点击选州，Shift+点击多选；绘制工具可连续拖过多个州，一笔只产生一个撤销步骤。海域同样可选、可上色。
- I 取色工具或“取该州存储色”按钮读取权威六位颜色，不采样边界、标签或选中高亮。选中高亮只显示在边缘，内部不再混入黄色。
- 绘制模式双击填所属国家；范围选项可切换州与当前归属国家，亦用于所选州上色。水域只填该州，不会把全世界 WTR 海域当作一个国家。
- 搜索接受原生州名、州 ID 和参考实体标签；结果可定位到只有一个像素的州。
- 选中单州后可改地图标签，留空恢复原名；上色与标签支持撤销、重做。
- V 选择或 H 平移模式拖动平移；绘制模式用空格或中键拖动平移。滚轮缩放，可开关州边界、地名标签和原生城市。Escape 取消未完成笔划。
- 保存下载 JSON；打开时先验证完整项目及数据修订号，失败不会覆盖当前文档。
- PNG 导出完整的 5120×2560 原生地图，保留已启用图层，不包含选中高亮。

快捷键：V 选择、B 绘制、I 取存储色、H 平移、0 全图、+/- 缩放；Ctrl/⌘+Z 撤销，Ctrl/⌘+Shift+Z 重做，Ctrl/⌘+S 保存，Ctrl/⌘+O 打开。

国家范围依据项目当前 owner，无覆盖时使用历史 entityTag，不依据 controller、颜色相同与否或 coreTags。未释放实体的核心声明不是当前国家边界。现有数据没有可靠的地理父级，因此只提供已验证的“州→当前归属国家”两级，不猜造省区或大洲范围；普通上色不会变更归属；国家面板的核心领土转交会编辑当前归属。

## 数据与边界

当前数据包含 11,894 个州、20,782 个省份定义、570 个参考实体和 884 个有效原生地点。其中 924 个州属于 WTR 海域；20,781 个省份实际出现在地图像素中。原始省份 0 没有像素，但仍保留独立的编码，不能与空白编码 0 混淆。

坐标为原生左上角像素，未经推测的经纬度转换。州锚点必须落在自己的真实像素内。城市来自原始胜利点与本地化资料；无法对应所在州的陈旧引用会省略，并在 provenance.json 中记录。国家首都州保留为源信息，不由此猜造首都城市。两个源文件缺失末尾括号采用字节指纹限定的解释修正，原始模组文件不被写入。

原生地图与名称来自 Historic Geographical Overhaul（`hgo_mod_2241701657`）。[来源账本](../../data/source_ledger.json)记录其出处与来源条款，[数据溯源文件](assets/default/provenance.json)记录精确输入与解释诊断；项目代码的许可不改变第三方数据的来源条款。

项目格式为 `scenario-forge-hgo` / schema 2（兼容读取 schema 1），绑定精确数据修订号。旧 HGO 共底/预览项目使用另一套地图，不能作为新项目导入。当前不提供现代地理投影、省份几何编辑或旧共底项目转换。

## 单独检查和打包

```powershell
npm --prefix apps/hgo test
npm --prefix apps/hgo run check
python -m pip install -r apps/hgo/requirements.txt
python -B -m unittest discover -s apps/hgo/tests -p 'test_*.py'
python -B apps/hgo/tools/validate_dataset.py apps/hgo/assets/default
python -B apps/hgo/tools/build_app.py --output .runtime/dist/hgo
```

独立打包器只需 Python 标准库。NumPy、Pillow 只用于源数据生成、数据校验及其测试；浏览器运行时没有 npm、CDN 或字体网络依赖。完整 Pages 构建会把该包放在 `/hgo/`，主编辑器位于 `/app/`。

默认独立包位于 `.runtime/dist/hgo`，返回链接按仓库根目录提供服务时的路径生成。放到其他目录或单独托管时，用 `--main-url` 指定主编辑器地址。

PR 中的纯 HGO 修改只选择 HGO 独立检查；同时修改主应用或发布桥接时，保留对应主应用检查。PR gate 会等待被选中的 HGO job 完成，网站发布仍走统一 Pages 构建。GPU 与真实浏览器行为仍需独立运行时检验，静态边界检查不代表这一层已经通过。

数据重建命令、资产格式和 Python 接口见 [英文技术说明](README.md)。

## 显示设置与资源占用

边界宽度按 CSS 屏幕像素计算，可调 0–2，默认 0.7；颜色和不透明度可调。州界采用该宽度，当前所属国家边界强调为 1.25 倍、上限 2 像素。选择轮廓绘于所选像素外侧，即使单像素州也保留内部存储色；最多 64 个可见微小选区显示定位圈。定位圈不代表新增地理细节，低缩放时源像素仍可能落在屏幕采样间隙。

城市点、城市名、州名和国家名共用低/中/高密度预算（96/180/300 项），城市点与文字一起避碰。自定义州名和有明确数据标记的首都优先；当前附带数据没有首都标记，不推断或虚构首都。布局使用元数据空间索引、分散的缩放显示阈值和有上限的跨帧保留，减少缩放闪变；没有可能晚到的异步布局结果。

显示设置随项目保存。缺少新可选项的 schema-1 旧项目使用默认值；新版保存为 schema 2，旧版会明确拒绝以避免丢失归属。ID 解码复用其 25 MiB 缓冲区；PNG 导出由三张大画布减为两张，并在编码前释放临时 WebGL 资源。本批仍保留独立导出渲染器，原生分辨率导出的画布和编码内存需求仍高于日常编辑。

## 国家与核心领土

展开侧栏“国家与核心领土”，可按名称或 tag 搜索，查看当前州数、国家基础色和手工涂色覆盖数。改基础色默认保留手工色；另一个明确的统一操作只移除该国家当前所属州的覆盖色。同色不代表同国，笔刷和国家范围填色仍只改颜色。

选择母国及核心候选后，预览“目标核心州 ∩ 母国当前所属州”。列表显示精确州、母国剩余、目标已有领土、手工色影响及目标颜色；这是地图归属编辑，不等于游戏允许释放。水域与异常 tag 隔离，不改源资产。多核心重叠按每次操作后的当前归属重算，不转交第三国的领土；文档变化后的旧预览须刷新。一次一个母国/目标，一条撤销记录完整还原。

首次创建的候选默认以 tag 为名称，采用母国基础色的受控变体，可手动改名改色。已有目标国家保持基础色；如要改其全境颜色，请使用国家列表。转交州是否覆盖手工色通过明确选项控制。颜色建议用固定色相的 HSL 变体和轻量 Lab 距离筛选；有限候选太相似时提示冲突，不能保证所有人或显示设备的辨识效果。缺乏可靠名称的核心 tag 不猜造历史名称。

新存档 schema 2 包含 owners、palette、createdCountries 与 paint/labels，统一支持撤销重做和完整原子校验。schema 1 旧文件保留涂色，以原始归属迁移。**新文件请直接在独立 HGO 页面打开**；未修改的主项目交接入口目前只接受 schema 1。PNG 输出当前归属边界、标签和颜色的图像；JSON 才完整保留可编辑归属，不能从 PNG 反推国家。
