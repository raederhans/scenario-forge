# HGO 原生地图工坊

HGO 是与主编辑器并行的子项目。它直接使用模组的原始像素地图，独立加载、渲染、保存和测试；海域与陆地的州使用同一套编辑工具。原始实体与核心资料保持只读，项目可编辑当前归属和国家基础色。

## 本地打开

在仓库根目录运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8000/apps/hgo/`。随附数据足以运行，无需安装或下载原始模组。浏览器需要 WebGL 2，显卡需支持至少 5120×2560 的纹理；完整性校验与 gzip 解码需要 localhost 或 HTTPS。

主编辑器的剧本面板、指南与网站首页均有 HGO 入口。主编辑器可将 schema-1 原生 HGO JSON 转交给独立页面；新 schema-2 文件请直接在 HGO 打开。双方通过限时、一次性项目交接传递旧版文档，不导入彼此的渲染器或状态。

## 编辑

- 点击选州，Shift+点击多选；绘制工具可连续拖过多个州，一笔只产生一个撤销步骤。海域同样可选、可上色。
- I 取色工具或“取该州存储色”按钮读取权威六位颜色，不采样边界、标签或选中高亮。选中高亮只显示在边缘，内部不再混入黄色。
- 绘制模式双击填所属国家；范围选项可切换州与当前归属国家，亦用于所选州上色。水域只填该州，不会把全世界 WTR 海域当作一个国家。
- 搜索接受原生州名、州 ID 和参考实体标签；结果可定位到只有一个像素的州。
- 选中单州后可改地图标签，留空恢复原名；上色与标签支持撤销、重做。
- V 选择或 H 平移模式拖动平移；绘制模式用空格或中键拖动平移。滚轮缩放，可开关州边界、地名标签和原生城市。Escape 取消未完成笔划。
- 保存下载 JSON；打开时先验证完整项目及数据修订号，失败不会覆盖当前文档。
- PNG 导出完整的 5120×2560 原生地图，保留已启用图层，不包含选中高亮。

快捷键：V 选择、B 绘制、I 取存储色、H 平移、0 全图、+/- 缩放；Ctrl/⌘+Z 撤销，Ctrl/⌘+Shift+Z 重做，Ctrl/⌘+S 保存，Ctrl/⌘+O 打开。

国家范围依据项目当前 owner，无覆盖时使用历史 entityTag，不依据 controller、颜色相同与否或 coreTags。未释放实体的核心声明不是当前国家边界。现有数据没有可靠的地理父级，因此只提供已验证的“州→当前归属国家”两级，不猜造省区或大洲范围；普通上色不会变更归属；国家面板的核心领土转交会编辑当前归属。

## 数据与边界

当前数据包含 11,894 个州、20,782 个省份定义、570 个参考实体和 884 个有效原生地点。其中 924 个州属于 WTR 海域；20,781 个省份实际出现在地图像素中。原始省份 0 没有像素，但仍保留独立的编码，不能与空白编码 0 混淆。

编辑坐标始终为原生左上角像素，州锚点必须落在自己的真实像素内。可选地理参考通过独立配准资产显示，不参与点击识别或编辑坐标。城市来自原始胜利点与本地化资料；无法对应所在州的陈旧引用会省略，并在 provenance.json 中记录。国家首都州保留为源信息，不由此猜造首都城市。两个源文件缺失末尾括号采用字节指纹限定的解释修正，原始模组文件不被写入。

原生地图与名称来自 Historic Geographical Overhaul（`hgo_mod_2241701657`）。[来源账本](../../data/source_ledger.json)记录其出处与来源条款，[数据溯源文件](assets/default/provenance.json)记录精确输入与解释诊断；项目代码的许可不改变第三方数据的来源条款。

项目格式为 `scenario-forge-hgo` / schema 2（兼容读取 schema 1），绑定精确数据修订号。旧 HGO 共底/预览项目使用另一套地图，不能作为新项目导入。地理配准只用于参考图层，不提供省份几何编辑或旧共底项目转换。

## 单独检查和打包

```powershell
npm --prefix apps/hgo test
npm --prefix apps/hgo run check
python -m pip install -r apps/hgo/requirements.txt
python -B -m unittest discover -s apps/hgo/tests -p 'test_*.py'
python -B apps/hgo/tools/validate_dataset.py apps/hgo/assets/default
python -B apps/hgo/tools/build_app.py --output .runtime/dist/hgo
```

默认数据集变化后，在仓库根目录运行 `python tools/build_landing_hgo_zoom.py`，重新生成展示页的 HGO 缩放图。

独立打包器只需 Python 标准库。NumPy、Pillow 用于源数据生成与校验，SciPy 用于离线地理配准；这些均非浏览器依赖。运行时没有 npm、CDN 或字体网络依赖。完整 Pages 构建会把该包放在 `/hgo/`，主编辑器位于 `/app/`。

默认独立包位于 `.runtime/dist/hgo`，返回链接按仓库根目录提供服务时的路径生成。放到其他目录或单独托管时，用 `--main-url` 指定主编辑器地址。

PR 中的纯 HGO 修改只选择 HGO 独立检查；同时修改主应用或发布桥接时，保留对应主应用检查。PR gate 会等待被选中的 HGO job 完成，网站发布仍走统一 Pages 构建。GPU 与真实浏览器行为仍需独立运行时检验，静态边界检查不代表这一层已经通过。

数据重建命令、资产格式和 Python 接口见 [英文技术说明](README.md)。

## 显示设置与资源占用

边界宽度按 CSS 屏幕像素计算，可调 0–2，默认 0.7；颜色和不透明度可调。州界采用该宽度，当前所属国家边界强调为 1.25 倍、上限 2 像素。选择轮廓绘于所选像素外侧，即使单像素州也保留内部存储色；最多 64 个可见微小选区显示定位圈。定位圈不代表新增地理细节，低缩放时源像素仍可能落在屏幕采样间隙。

城市点、城市名、州名、国家名和地貌名称共用低/中/高密度预算（96/180/300 项），城市点与文字一起避碰。地貌名称另受 12/24/40 项子上限约束，不额外增加总预算。自定义州名和有明确数据标记的首都优先；当前附带数据没有首都标记，不推断或虚构首都。布局使用元数据空间索引、分散的缩放显示阈值和有上限的跨帧保留，减少缩放闪变；没有可能晚到的异步布局结果。

底图配色默认“国家原色”（`baseMapStyle: "political"`），可切换“专题浅底”（`"thematic"`），使陆地底色变浅，并将同一当前归属内部的州界不透明度降至设置值的 0.3。WTR 水域颜色、实际存储的填色、取存储色和归属不变；该设置随 JSON 保存并用于 PNG。资源与基础设施模式自动使用中性浅色陆地底图，不修改保存的 `baseMapStyle`；关闭指标后恢复原设置。编辑和查看实际填色时，请先关闭指标，再选择“国家原色”（`political`）。

显示设置随项目保存。缺少新可选项的 schema-1 旧项目使用默认值；新版保存为 schema 2，旧版会明确拒绝以避免丢失归属。ID 解码复用其 25 MiB 缓冲区；PNG 导出由三张大画布减为两张，并在编码前释放临时 WebGL 资源。本批仍保留独立导出渲染器，原生分辨率导出的画布和编码内存需求仍高于日常编辑。

## 国家与核心领土

切换到侧栏“国家”页，可按名称或 tag 搜索，查看当前州数、国家基础色和手工涂色覆盖数。改基础色默认保留手工色；另一个明确的统一操作只移除该国家当前所属州的覆盖色。同色不代表同国，笔刷和国家范围填色仍只改颜色。

选择母国及核心候选后，预览“目标核心州 ∩ 母国当前所属州”。列表显示精确州、母国剩余、目标已有领土、手工色影响及目标颜色；这是地图归属编辑，不等于游戏允许释放。水域与异常 tag 隔离，不改源资产。多核心重叠按每次操作后的当前归属重算，不转交第三国的领土；文档变化后的旧预览须刷新。一次一个母国/目标，一条撤销记录完整还原。

首次创建的候选默认以 tag 为名称，采用母国基础色的受控变体，可手动改名改色。已有目标国家保持基础色；如要改其全境颜色，请使用国家列表。转交州是否覆盖手工色通过明确选项控制。颜色建议用固定色相的 HSL 变体和轻量 Lab 距离筛选；有限候选太相似时提示冲突，不能保证所有人或显示设备的辨识效果。缺乏可靠名称的核心 tag 不猜造历史名称。

新存档 schema 2 包含 owners、palette、createdCountries 与 paint/labels，统一支持撤销重做和完整原子校验。schema 1 旧文件保留涂色，以原始归属迁移。**新文件请直接在独立 HGO 页面打开**；未修改的主项目交接入口目前只接受 schema 1。PNG 输出当前归属边界、标签和颜色的图像；JSON 才完整保留可编辑归属，不能从 PNG 反推国家。

## 可选地形、夜光与原生指标

侧栏顶部常驻搜索、**编辑｜图层｜国家**和当前选择摘要。编辑页提供颜色与名称操作；图层页统一放置边界、标签、地形、河流、现代夜光和昼夜；国家页保留国家与核心领土操作。三页各自保留滚动位置，切页不重建控件、不修改项目、不启用图层或加载地图资源；国家页隐藏时暂停国家列表查询。在标签页上可用左右方向键、Home、End 切换。图层关闭时隐藏对应参数，开启后展示常用项，其余参数与数据说明可展开查看。

地形、河流、现代夜光和昼夜默认关闭；地名中文数据在基础地图就绪后独立加载。图层失败不会阻断基础地图，可单独重试。所有地图显示设置随 JSON 保存，侧栏分页与折叠属于本次页面的 UI 状态。PNG 使用导出开始时的文档、显示设置、质量档和太阳时刻；所需图层尚未加载时等待加载，失败会明确中止该次导出。关闭失败图层并选择英文后仍可导出基础地图。

- **地形与地貌**：原生 terrain 分类与主世界现代地貌各保留独立类别，可选原生、地貌分区或组合。单通道索引同时保留两种来源；原生地形覆盖约 99.98% 非水域陆地。地貌和河流使用城市控制点配准，现代参考域约覆盖 85.46% 陆地。它是参考配准，不是精确地理测绘；未覆盖区域不填造现代分类。地貌分区和组合模式可显示 382 个已配准名称点，放大后按等级逐步出现，支持简体中文、英文和双语；与州名开关独立。切回原生地形或关闭“地貌名称”会释放名称资源。上游名称错配的修正绑定精确 ID 与原文字段，未确认的中文保留英文。
- **河流**：现代 Natural Earth 河流经相同映射重采样；未重叠的原生模组河线作补充，两者在原始资产中保留不同标记。保留 HGO 原生水域识别，不覆盖州归属。“河流粗细”0.5–3 会实际收缩或扩张边缘，1 为默认参考粗细，随地图缩放；数值不是屏幕像素或精确倍率。不透明度独立控制，原生补充河线与现代河线使用相同不透明度。离线距离场沿用单通道纹理，不增加解码尺寸；相邻对角细河线作局部连接，避免调细后断裂。
- **夜光与昼夜**：只使用仓库已有的 2016 现代夜光派生网格。该资料的上游输入身份仍为 `not_attested`，本次没有重新获取或认证卫星原始数据。夜光使用较严格地理参考域，昼夜允许较宽的近似域（约 97.22% 陆地）；可靠度类别不代表统计概率。支持手动 UTC 时间、当前 UTC、循环演示和晨昏过渡调节；不模拟 1936 年城市亮度。
- **资源与设施**：17 项指标来自原生州文件在 1936.1.1 的配置，原生数值未改。建筑单位按模组 `common/buildings/00_buildings.txt` 核对：基础设施、空军基地、防空设施和雷达站显示原生等级；当前海军基地、海岸要塞和陆上要塞数据是省份等级之和，不是设施个数；工厂、船坞和合成炼油厂保留配置数量。基础设施只读显式州字段；其他建筑优先使用显式州值（含零），否则汇总有效省份值，不重复相加。未记录值保持缺失，原始 manpower 未作为人口接入。
- **地名**：简体中文、英文、双语；自定义名称优先，中英及旧拼写可搜索。当前中文覆盖州 4,962/11,894、实体 569/570、地点 695/884；水域州覆盖 715/924。华沙、克拉科夫等采用常用中文译名，列宁格勒、斯大林格勒、柯尼斯堡、巴达维亚和马德拉斯保留源数据的历史名称，不按现代城市主名替换。271 个州和 121 个地点的占位名显示为带 ID 的未命名项，不计入已翻译数量；其中 88 个源 `STATE_` 尚无真实地名。三处国家英文拼写纠错保留旧名搜索；仍有歧义的名称保留原文。离线简体转换使用随附 OpenCC 1.1.9 字典及许可证。

此前未译的 184 个有名地点已全部审核：116 个补入有依据的中文名，68 个保留原名并记录待核原因。首批州名审核覆盖 146 个陆地州和全部 417 个此前未译水域州，其中 302 个补入中文、261 个保留原名。水域组合保留围垦区、期次、水坝、陆桥和拟建点含义。

[地点审核表](assets/overlays/localization/place_reviews.json)和[州名审核表](assets/overlays/localization/state_reviews.json)逐条绑定原生 ID、原名和实体，地点另绑定所属州。同名地点译文仅在同一州、同一实体且源名一致时用于州名，不传播到其他同名州。第聂伯罗彼得罗夫斯克、伏罗希洛夫格勒、新里斯本等保留源历史名；没有可靠中文依据的条目不新造音译。现成中文资料与有来源词素的组合翻译分别记录，`verified` 仅表示已有可核对的中文记录，不表示官方标准译名认证。已明确排除 `Ha'il→冰雹`、`Ivanovo→约翰尼斯施塔特` 等错误候选。

本轮未变更地理配准。固定的配准独立确认集共 88 个控制点，RBF 正向误差 p95 约 11.51 原生像素、最大约 17.80；部分地区样本很少，不能据此保证每一条河线。极地、远离控制点的区域及 HGO 人工形变仍有限制。真实地形晕染暂缓：原生高度图只有两个有效高度，没有已验证配准的真实 DEM。道路、铁路、人口和海深不在本批范围。

“图层精度”默认均衡，可切换精细。均衡档地形为 1280×640，河流为 2560×1280；精细档分别为 2560×1280、5120×2560。地形采用类别最近邻，不平均类别编码；河流使用 2×2 最大值采样保留单像素细线。两项合计解码数据从 15.625 MiB 降至 3.90625 MiB，减少 75%，这是资产占用变化，不等同 FPS 提升。切换档位会取消/释放上一档资产，PNG 使用所选质量档。

主世界矢量只在离线构建时参与配准和栅格化，交互期间不重新投影或遍历矢量。整幅纹理采用 `CLAMP_TO_EDGE`，没有瓦片接缝，无需额外 tile padding；低分辨率海岸边缘再用原生省份水域表精确裁切，避免河流和地貌越过水域边界。太阳向量格为 512×256 RGBA8：编码法向量按独立 alpha 显示权重预乘，有效域边缘用 4 格 smoothstep 渐隐。单次 LINEAR 纹理采样后恢复法向量，不新增纹理，不扩大有效域；旧 confidence 类别独立保留，不表示统计概率。

图层不导入主世界渲染器或全局状态。`assets/overlays/catalog.json` 独立绑定基础 dataset revision；基础 ID/core/places 及其 revision 不变。按启用项读取、校验并解压，关闭后释放大块 CPU/GPU 图层数据，运行时可选资源的解码字节预算为 48 MiB（不等同浏览器进程总内存）。英文拼写纠错和双语搜索共用的本地化数据保留到会话销毁。分类、河流、灯光使用单通道纹理；基础设施与其他建筑填色更新小型省份颜色表，资源圆使用缓存索引和独立符号布局；关闭可视化时使用基础着色器。静止手动时刻没有持续动画，循环模式每 100 ms 重绘，隐藏页面停止计时。

打包器验证并携带目录声明的图层和溯源闭包，包含人工译写依据及 OpenCC 许可证；离线工具或主世界运行时代码不进入浏览器包。重建来源、配准统计和缺失明细以各 sidecar 的 manifest/provenance 为准。

六项资源以州原生锚点上的比例圆显示，圆面积与原生游戏资源值成正比，不代表现实吨数、密度或矿点位置。同一指标始终使用全图最大值，统一尺寸系数随缩放有限增大，数值比例不变。每项指标缓存正值索引，首次加载时优先排列拥挤锚点邻域，以数值和州 ID 稳定处理同级项。每个符号的常规布局和边缘修正各通过屏幕格网检查最多 65 个确定性圆盘候选位置，优先尝试短位移。最多位移 30 CSS 像素，引线回指州锚点，并为视口边缘保留间距。普通平移复用当前缩放的布局；不在每帧重建邻域排序，不聚合或剔除正值州。无法解开的重叠保留半透明圆，面板提示数量；可放大或点击州查看数值。零与缺失均不画数量圆，在州详情中区分。符号为标签预留避碰空间，不参与原生点击识别。

基础设施采用固定 0–10 的顺序等级色，当前数据最大值为 9 也不拉伸色阶；同级跨国家保持同色。等级填色覆盖装饰图层的陆地颜色，不受指标不透明度影响；缺失州保留浅底，与已记录的 0 级区分。地图与等级图例共用 `infrastructureColor`。其他建筑仍使用原有整州填色：按全图已记录值线性归一，恒定值显示中间色，缺失透明，明确零值参与比较；其图例显示图层原色，地图填色仍受底图、其他图层和不透明度影响。

河流粗细仅控制新增河流叠加，原生水域地块保持原宽度。照明数据说明披露 0.5° 夜光衍生采样、原始影像尚未核验，以及高纬度和配准不足区域可能出现的明暗接缝。
