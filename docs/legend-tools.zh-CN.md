# 图例查找与导出

打开编辑器的 **图层 → 图例**。尚无图例时，先选择生成模式并点击“生成图例”。

在“名称或 #色号”中输入名称或颜色，可以查找所有页面的图例项。名称支持部分匹配；多个词需要同时匹配。色号可以输入完整的 `#112233` 或简写 `#123`。类型菜单可筛选普通颜色和特殊区域。每页显示最多 10 项，匹配结果多时可继续翻页。

输入后按 Enter 可聚焦第一个结果，方便修改名称。按 Escape 或点击“清除”会恢复全部类型和条目。查找本身不会修改地图、名称或颜色。

点击“导出 SVG”或“导出 CSV”会下载当前图例的全部条目，包含其他页面及被搜索暂时隐藏的条目。导出使用点击时的名称，包含当前可见的特殊区域图例。

- SVG 是独立矢量文件，含名称、色块和特殊区域纹理，适合排版或放入文档。
- CSV 使用 UTF-8 编码，可在电子表格中查看名称、颜色及样式参数。名称中的逗号和换行会保留。

导出不会保存整个项目。需要保留地图编辑内容时，请使用顶部的“保存项目”。

展开“CSV 导入预览及确认”可把修改后的 CSV 带回编辑器。当前导出的新版 CSV 含剧本、版本和条目 ID；请保留这些列。普通颜色类别只支持修改名称，特殊区域可修改名称和已有样式参数。

先选择文件并查看当前值与拟导入值，再勾选需要更新的行，点击“查看所选更改”，最后点击“确认导入”。未勾选的行不会改动。一次确认形成一条历史记录，可以用底部的撤销、重做按钮恢复。

旧版八列 CSV 只提供比较预览。不同剧本或版本、未知或重复 ID、无效样式均不能直接写入。若预览后又编辑了目标条目，请重新比较后再确认；导入会拒绝覆盖这段较新的编辑。没有剧本版本信息的地图也保持只读预览。

若想查看哪些国家或图例颜色重复或相近，打开 **调色板 → 颜色相似性检查**。点击结果中的图例项，会清除图例搜索条件、跳到对应页面并聚焦名称；点击国家会定位到国家检查器。详见[颜色相似性检查](color-similarity-check.zh-CN.md)。
