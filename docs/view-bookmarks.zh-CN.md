# 视图书签

缩放工具旁的 ☆ 按钮打开视图书签。先移动或缩放地图，输入名称后点“保存当前视图”；点击已保存的名称即可返回该位置和缩放比例。列表也支持改名和删除。

书签按当前剧本分别保存。基础地图的政治模式和空白模式也各有列表。切换剧本、刷新或重新打开页面不会自动应用书签，需要主动点击名称。窗口尺寸变化后仍按地图投影中心还原视图，并遵守现有平移和缩放边界。

书签只保存名称、位置和缩放，不保存或修改领土、归属、颜色，也不进入地图编辑的撤销历史。最多保存 50 个书签，每个名称最长 80 个字符。

书签保存在当前浏览器的本地存储中，不随项目文件导出，也不会跨设备同步。清除网站数据会移除书签；浏览器不允许存储或空间不足时，菜单会显示错误，不会把未保存的操作报告为成功。
