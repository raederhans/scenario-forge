# 编辑器 UI 规范（制图台）

2026-10-29 起，编辑器（`/app/`）与落地页（`landing/`）共用一套视觉语言。本文是样式与排版的唯一依据：新增或修改界面时先查这里，规范没有覆盖的情况先补规范再写样式。

## 1. 方向

**制图台**：纸面中性色承载面板，墨色画布承载地图，铜色只用于"当前、选中、主操作"。

- 地图是主角。界面外框用暖灰纸面，地图周围用和落地页同源的墨色，政治色块在深底上最清楚。
- 一个强调色。铜色（`--accent`）表示"你现在在这里 / 这一步最重要"；蓝色只保留给信息提示。
- 密度优先、层级清楚。编辑器是长时间使用的工具：控件 32 px 高、正文 13 px，靠字重和间距分层，不靠边框和阴影堆叠。
- 同一件事只有一种画法。同类控件只有一套样式，同一功能只有一个主入口。

## 2. 设计令牌

所有颜色、间距、圆角、阴影、层级、动效只通过 `css/style.css` 顶部 `:root` 的令牌引用。旧变量名（`--bg-*`、`--text-*`、`--color-accent` 等）保留为新令牌的别名，避免一次性改全部引用。

规则：
- 面板里不出现 `#hex` / `rgb()` 字面量。确需一次性颜色（地图符号、图例样本）写在对应模块里并注明原因。
- 半透明玻璃面板（`rgba(255,255,255,.9)` + blur）只保留给浮在地图上的控件：上下文条、缩放条、工具坞。侧栏用不透明 `--surface-panel`。

### 2.2 字体与字号

- 界面字体沿用系统字体栈：`--font-ui: "Segoe UI Variable", "Segoe UI", "PingFang SC", "Microsoft YaHei UI", "Noto Sans SC", sans-serif`。编辑器不新增外部字体请求。
- 品牌字体：`--font-brand: "Map Garamond", "Map Noto Serif SC", Georgia, serif`（复用已自托管的地图标注字体，见 `css/map-label-fonts.css`），只用于顶栏字标、对话框大标题、空状态标题，与落地页的衬线标题呼应。
- 等宽：`--font-mono: "Cascadia Mono", Consolas, "SFMono-Regular", monospace`，用于颜色值、ID、坐标。
- 字号沿用五档刻度 `--fs-xs 12 / --fs-sm 13 / --fs-md 14 / --fs-lg 16 / --fs-xl 18`，再加 `--fs-2xl 22`（对话框标题）。
- 字重只用 400 / 500 / 600 / 700。正文 400，控件文字与标签 500，标题 600，数值强调 700。不再使用 650、760、800。
- 行高：正文 1.45，控件 1.2，标题 1.25。中文环境 `:lang(zh)` 正文行高 1.6、不加字距。
- 普通控件文字 `letter-spacing: 0`。
- 大小写：按钮与标题一律句式大小写（"Apply color to scope"），不用 Title Case；全大写只用于 `--fs-xs` 的分组眉标，且加 `letter-spacing: .06em`。

### 2.3 间距、尺寸、圆角

- 间距 2 px 细分、4 px 为主：`--space-1 4 / --space-1h 6 / --space-2 8 / --space-2h 10 / --space-3 12 / --space-4 16 / --space-5 20 / --space-6 24 / --space-8 32`。6 和 10 是现有高频值，保留以免大面积改尺寸；新代码优先用 4 的倍数。
- 控件高度：`--control-sm 28`（行内工具、芯片）、`--control-compact 32`（侧栏密集控件）、`--control-md 36`（默认）、`--control-lg 40`（对话框主操作）。`(pointer: coarse)` 下最小 44，且对所有宽度生效。
- 列表行最小高度 32 px，整行可点。
- 圆角：`--radius-xs 4`（色块、标签）、`--radius-sm 8`（按钮、输入框、芯片）、`--radius-md 12`（卡片、弹层、菜单）、`--radius-lg 16`（对话框、浮动工具坞）、`--radius-pill 999px`（只用于开关、计数徽标和浮动圆形把手）。
- 侧栏内边距 `--space-4`，分组之间 `--space-5`，组内控件 `--space-2`。

### 2.4 阴影、层级、动效

- 阴影三档：`--shadow-1`（悬浮控件）、`--shadow-2`（菜单、弹层）、`--shadow-3`（对话框）。侧栏不加阴影，用 `--line-1` 分隔。
- 层级：`--z-map-overlay 10 / --z-dock 20 / --z-sidebar 30 / --z-popover 60 / --z-overlay 100 / --z-dialog 110 / --z-toast 120`。
- 动效：`--dur-enter 140ms`（面板切换淡入）/ `--dur-fast 160ms`（菜单下拉、悬停）/ `--dur-base 260ms`（栏宽折叠），缓动 `--ease: cubic-bezier(.2, 0, 0, 1)`。面板淡入比菜单略快是有意的节奏差，不要合并。
- 状态色用"浅底 + 深字"：toast、提示条、徽标不再用亮色实底配白字。`prefers-reduced-motion: reduce` 下全部过渡降为 0。

## 3. 组件

每类组件只有一套基础类，变体用修饰类。

### 3.1 样式分层与目录

- 全部样式按 `@layer tokens, base, components, panels, overrides` 排序，顺序声明在 `css/style.css` 第一行。层序决定胜负，层内才比特异性和先后。
  - `tokens`：设计令牌（`:root` 自定义属性）。
  - `base`：重置、全局元素、页面骨架（布局、侧栏外壳、滚动条、排版）。
  - `components`：通用组件（卡片、输入与下拉、按钮、工具类、色块、提示气泡），以及 `css/components/` 下的文件。
  - `panels`：某个面板专用的规则（交通工作台、特殊区域、导出工作台、检查器……）。
  - `overrides`：`style.css` 末尾的收口覆盖、`editor-workspace.css`、`editor-shell.css`、`editor-tool-guidance.css`。面板迁到组件后，删掉它在这一层的对应覆盖，这一层只减不增。
- **所有规则都必须在某一层里。** 未分层的规则压过一切分层规则，新增样式表时整个文件包在 `@layer <层名> { … }` 里。
- 分层时按段落归层，但有 137 条规则为保持原有层叠结果放在了相邻层（原来靠高特异性压过后面的规则）；它们在源文件里就地用单独的 `@layer` 块包住。改这些规则时用画廊截图确认没有连带变化。
- `!important` 在层里是反转的：越早的层里的 `!important` 越强。只在"隐藏 / 无障碍隐藏 / 降低动效"这类必须压过一切的场合用；新代码不加。
- 组件和面板样式以组件类为作用域，不依赖 `#leftSidebar`、`#mapContentStack` 等所在栏。二级折叠用 `data-level="2"` 或 `.disclosure--nested` 显式标记，不按 DOM 深度推断。
- 通用规则用 `:where()` 包住选择器，把特异性降到 0，让面板规则不用堆选择器就能覆盖。
- 目录：组件的 JS 放 `js/ui/components/`（工厂函数返回真实 DOM 节点，保留原生 `input` / `change` 事件），样式放 `css/components/`。`js/ui/` 下的旧路径（`styled_selects.js`、`app_dialog.js`、`toast.js`、`ui_icons.js`）只剩重导出，新代码直接从 `components/` 导入。
- 对照物：`tests/e2e/ui_gallery/gallery.html` 摆出全部控件家族和状态，`npx playwright test tests/e2e/ui_gallery` 比对截图基线。改动组件样式前后都跑一次。

### 3.2 命名规则

- 基础类是名词（`.btn`、`.input`），变体用双连字符修饰（`.btn--primary`、`.btn--sm`），状态用 `is-*`（`is-active`、`is-selected`、`is-danger`）或 ARIA 属性（`aria-pressed`、`aria-selected`、`aria-expanded`）。
- 面板专用的类以面板名开头（`transport-workbench-*`、`special-zone-*`），只写布局和面板特有的东西，外观继承基础类。
- 旧类名（`btn-primary`、`sidebar-action-secondary`、`secondary-btn` 等）是别名：`index.html`、JS 和测试里照常使用，样式由基础规则统一提供，不再单独写外观。新代码用基础类。

### 3.5 通用状态

状态：所有可交互元素必须有 hover、`:focus-visible`（2 px 实色 `--accent` outline，对纸面底 ≥ 3:1；不得 `outline: none` 而无替代，半透明色不能作为唯一焦点指示）、disabled（`--ink-400`、不可点）、selected（`--accent-soft` + `--accent` 文字）。

- 列表行、菜单项和图标开关选中时使用 `--accent-soft`；分段控件选中使用 `--surface-raised` 滑块与 `--accent` 字、600 字重。
- 悬停分两类：侧栏和面板内用 `--surface-sunken` 底，按钮另加 `--line-2` 边；地图浮层上用不透明 `--surface-raised` 底与 `--line-2` 边，不加阴影。标签、折叠标题、列表行、选择框都要有悬停反馈。
- 贴边的菜单项、列表行和整行按钮，焦点 outline 偏移为 -2 px。

## 4. 壳层排版

```
┌ 顶栏 56px ───────────────────────────────────────────────────────────────┐
│ 字标  项目▾  剧本▾  · 保存状态            撤销 重做 │ 导出  [保存] │ ?  语言  账户 │
├ 左栏 ─────┬──────────────── 地图画布（墨色） ─────────────────┬ 右栏 ──────┤
│ 对象 图层 调色板 │ 上下文面包屑                         缩放条 │ 检查器|图层设置 │
│          │                                                │            │
│          │               工具坞（浮动，单行）              │            │
└──────────┴────────────────────────────────────────────────┴────────────┘
```

- 顶栏（高 56 px）：左侧是"你在编辑什么"（字标、项目菜单、剧本菜单、保存状态），右侧是"对它做什么"（导出、保存）和全局工具（指南、帮助菜单、语言、账户）。指南保持独立按钮（关闭指南时焦点回到它）；帮助菜单（问号图标）收纳键盘快捷键、命令面板（Ctrl+K）和 GitHub；Dev 只在开发者模式下出现。
- 左栏一级标签：对象 / 图层 / 调色板。「图层」是分组图层列表：政治与边界 / 地理 / 聚落与交通 / 专题与标注 / 地图外观，顶部有搜索；显示画质、渲染试验等全局设置在「地图外观 › 显示与性能」，不放在任何图层页里。
- 右栏属性页三级层级：页标题 16/600 → 分组 13/600 墨色 + 上分隔线（静态分组与可折叠分组同级）→ 字段 13/400 次级墨色 → 说明 12/400。分组内再套的折叠是二级（12 px 灰色、左缩进竖线）。每页基础区只放常用控件，其余进「高级」「更多选项」「局部调整：…」等默认关闭的折叠。
- 上下文条是面包屑：`剧本 › 国家 › 当前地块`，用 `›` 分隔的文字链接；视图模式（Visual Color 等）是独立的小分段控件，不和面包屑混排。
- 折叠柄、缩放、手风琴全部换 SVG 图标。
- 地图画布底色 `--surface-canvas`，与落地页一致。

响应式三档（与 #314 一致，只收敛取值）：
- `≥1280`：两栏常开。
- `1024–1279`：同一时间只展开一侧栏，展开一侧时另一侧自动收起；工具坞放得下就单行，放不下按组折行，不得用横向滚动隐藏控件。
- `<1024`：两栏改为覆盖式抽屉；`<768` 显示一次性提示"编辑功能建议在桌面端使用"（放在地图底部、折叠工具坞上方：项目栏下沿紧挨面板与缩放等地图入口，不能遮挡），关闭后不再出现；默认进入只看地图的布局。

## 5. 层级架构

本章统一编辑器从应用外壳到字段内部的层级关系。沿用“制图台”的纸面中性色、墨色画布、铜色强调和现有基础令牌，以**连续纸面、有限分隔、稳定排版、逐级收紧的间距**组织界面。

层级由内容的职责决定，不由类名、DOM 深度或是否带边框决定。新增面板必须先确定各部分的层级，再选择组件与样式。

### 5.2 层级定义

#### 5.2.1 七级语义模型

| 层级 | 名称与职责 | 可承载内容 | 允许的内容子级 |
|---|---|---|---|
| **L0** | 应用壳：安排地图、顶栏、侧栏与浮层挂载位置 | 全局布局、地图画布、表面定位 | L1；地图及布局基础节点 |
| **L1** | 栏与浮层表面：确定任务边界、定位、尺寸和遮挡关系 | 侧栏、工作台外壳、对话框外壳、菜单、工具坞、反馈表面 | 通常 L2；紧凑表面可直接承载 L5、L6 |
| **L2** | 页：一个明确的编辑对象或任务上下文 | 页标题、状态摘要、说明、区段、正文、页脚 | L3；简单内容可跳至 L4、L5、L6 |
| **L3** | 区段：页面中的一级主题 | “外观”“数据来源”“成员”“输出设置”等成组内容 | L4、L5、L6 |
| **L4** | 子组：区段内部确有必要进一步区分的内容 | 高级选项、条件参数、独立预览、对象摘要、变体组 | L5、L6 |
| **L5** | 行：一次输入、一次选择或一个重复条目 | 字段行、开关行、键值行、图层行、菜单项、结果项 | L6 |
| **L6** | 字段内部：最小的信息和交互组成 | 标签、输入、值、单位、图标、帮助、错误提示 | 原子组件内部节点；不再形成分组 |

允许省略没有实际职责的层级：

```text
普通属性页
L1 右栏
└─ L2 当前图层页
   ├─ L3 基础外观
   │  ├─ L5 颜色行 → L6 标签、色块、颜色值
   │  └─ L5 透明度行 → L6 标签、滑块、数值
   └─ L3 高级设置
      └─ L4 局部调整
         └─ L5 字段行 → L6 标签、输入、说明

紧凑菜单
L1 菜单表面
└─ L5 菜单项 → L6 图标、名称、快捷键
```

不得为了凑齐层级，给每个字段增加区段或卡片。

#### 5.2.2 层级不等于 DOM 深度

以下节点不自动增加层级：

- 滚动容器、网格容器、布局列、挂载点。
- 被提升为当前页内容、且已隐藏旧标题的 Appearance 包装节点。
- 为事件代理、测试适配或样式兼容保留的旧节点。
- 页标题的布局容器、图标容器、值与单位的排列容器。

页面内部的局部视图切换也不自动产生第二个 L2。例如，交通工作台检查列中的显示、数据、检查页签，可以替换该区段的内容；只有切换完整任务上下文时，才定义为 L2 页面切换。

工作台中的列按职责判断：

- 纯布局列不计层级。
- 有独立名称和完整职责的“镜头”“预览”“检查器”等列，作为 L3。
- 列内继续分组时使用 L4，不再重新开始一套“页面 → 区段 → 卡片”。

### 5.3 排版角色

#### 5.3.1 角色令牌

排版角色统一引用现有字号，不新增字号档位。

`--type-<role>` **只表示字号**，搭配 `--type-<role>-weight`、`--type-<role>-leading`、`--type-<role>-color` 使用。不得有的角色存字号、有的角色存整条 `font` 简写。

| 角色令牌 | 字号映射 | 字重 | 行高 | 颜色 | 适用位置 |
|---|---|---:|---:|---|---|
| `--type-page-title` | `--fs-lg`，16 | 600 | 1.25 | `--ink-900` | L2 页标题、工作台总标题 |
| `--type-dialog-title` | `--fs-2xl`，22 | 600 | 1.25 | `--ink-900` | 普通任务对话框的主标题，使用 `--font-brand` |
| `--type-section-title` | `--fs-sm`，13 | 600 | 1.25 | `--ink-900` | L3 静态与折叠标题 |
| `--type-group-title` | `--fs-xs`，12 | 600 | 1.25 | `--ink-700` | L4 子组、子折叠、独立预览标题 |
| `--type-label` | `--fs-sm`，13 | 500 | 1.45 | `--ink-700` | 编辑字段标签、列表项名称 |
| `--type-control` | `--fs-sm`，13 | 500 | 1.2 | `--ink-900` | 按钮、菜单项、页签文字 |
| `--type-body` | `--fs-sm`，13 | 400 | 1.45 | `--ink-900` | 正文、操作说明 |

| `--type-value` | `--fs-sm`，13 | 400 | 1.2 | `--ink-900` | 数值、只读值、输入内容 |

补充规则：

- 中文多行正文、帮助、元信息和换行标签使用行高 1.6；标题仍使用标题行高。
- 数值强调可使用 700；普通字段值不统一加粗。连续数值使用等宽数字，ID、坐标、颜色值使用 `--font-mono`。
- 主按钮使用 600，作为 `control` 角色的主操作变体。
- 对话框的 22 px 是页面标题的限定变体。工作台、菜单、地图弹层不能因为“浮起来”就使用 22 px。
- 顶栏字标保留现有品牌字体、18 px、500；品牌字标不充当每个页面的标题。
- 页标题、区段标题、子组标题和按钮均使用句式大小写。
- 全大写只允许用于英文眉标，并使用 `.06em` 字距；中文眉标不加字距。
- 眉标必须提供标题之外的分类信息。不得同时出现含义相同的眉标、标题和卡片标题。
- `--ink-400` 只用于禁用或非必要占位信息，不用于需要阅读的帮助文字。

#### 5.3.2 旧变量的迁移关系

| 旧变量或写法 | 目标角色 | 迁移要求 |
|---|---|---|
| `--left-panel-font-section`、`--inspector-font-section`、`--sidebar-section-size` | `page-title` 或 `section-title` | 根据实际职责逐处拆分；不得整体替换为同一个字号 |
| `--left-panel-font-card-title`、`--inspector-font-card-title`、`--sidebar-card-size` | `section-title`、`group-title` 或 `label` | 先判断原“卡片”是一级区段、子组还是列表项 |
| 各组 `*-control`、`--sidebar-control-size`、`--editor-control-size` | `control`、`label`、`value` | 按文字用途拆分，取消面板位置决定字号 |
| 各组 `*-label`、`--sidebar-label-size` | `label` 或 `meta` | 编辑标签与只读键名分开 |
| 各组 `*-meta`、`--sidebar-meta-size`、`--editor-meta-size` | `meta` 或 `help` | 状态摘要与解释性文案分开 |
| `.section-header`、`.section-header-block` | 对应层级标题角色 | 不再由旧类名固定为 14/700 或 12/700 |

迁移期间允许保留兼容别名，但新代码只引用角色令牌。一个旧变量被用于多个角色时，必须先迁移使用点，不能用一个别名掩盖不同职责。

### 5.4 各层规格卡

以下数值均以 px 表示，实现时引用对应令牌。所有“间距”按布局盒边缘计算；标题行自身的内边距不再重复作为外部间距添加。

同一容器只采用一种主要分隔手段。阴影只表达浮起关系，选中背景和焦点描边只表达交互状态，不用于制造额外内容层级。

#### L0：应用壳

| 项目 | 规格 |
|---|---|
| 标题 | 无通用标题；顶栏字标按品牌角色 |
| 内边距 | 应用壳为 0；贴边侧栏、顶栏与画布直接相接 |
| 兄弟间距 | 贴合区域为 0；脱离边缘的浮层安全留距通常 24，窄屏 12 |
| 子级组织 | 由壳层布局安排，不给每个区域再套卡片 |
| 主分隔手段 | 背景色阶：`--surface-app`、`--surface-panel`、`--surface-canvas` |
| 圆角、阴影 | 无 |
| 折叠 | 不折叠应用壳；侧栏收起属于 L1 布局状态 |
| 说明与空状态 | 全局启动、加载失败等放在独立状态表面；不占用任意属性页 |

#### L1：栏与浮层表面

| 项目 | 规格 |
|---|---|
| 标题 | L1 不另设内容标题；可见任务标题归 L2 |
| 内边距 | 承载完整页面时为 0，由 L2 负责内容边距；紧凑菜单、toast、工具坞按 5.8 |
| 兄弟间距 | 侧栏贴合为 0；浮动控件通常 12，不能遮挡相邻入口 |
| 子级间距 | 互斥页面无间距；少数并列任务区域默认 24 |
| 主分隔手段 | `1px solid var(--line-1)` 边界：侧栏只画朝向画布的一边；浮层画外边界 |
| 背景 | 不透明 `--surface-panel`；玻璃效果仅限地图上下文条、缩放条、工具坞 |
| 圆角 | 贴边栏为 0；菜单和普通弹层 12；对话框、工作台、工具坞 16 |
| 阴影 | 侧栏无；地图浮动控件用 `--shadow-1`，菜单用 `--shadow-2`，模态任务表面用 `--shadow-3` |
| 折叠 | 可收起或关闭整个表面；不使用内容区段的 chevron 代替关闭按钮 |
| 说明与空状态 | 交由当前 L2；菜单、toast 等紧凑表面可直接承载自身说明 |

L1 的外框、圆角和阴影只能由一个节点负责。不得让 overlay、panel、shell 连续三层各画一遍表面。

#### L2：页

| 项目 | 规格 |
|---|---|
| 标题 | `page-title`；普通任务对话框使用 `dialog-title` 限定变体 |
| 内边距 | 侧栏正文 16；宽工作台、普通对话框正文 24；窄布局统一 12 |
| 兄弟间距 | 同一宿主的页面互斥显示；并列任务区域为 24 |
| 子级间距 | 一级区段间 20；页头与首个内容区之间 16 |
| 主分隔手段 | 留白 |
| 背景、边框 | 继承 L1；正文不再添加白底、外框或顶部装饰条 |
| 圆角、阴影 | 无 |
| 折叠 | 页面不折叠；使用页签、导航、返回或关闭切换 |
| 说明 | 页标题后放一段必要说明；上下文摘要与说明之间 8，不再重复页标题 |
| 空状态 | 在本页正文中替代缺失内容；20 px 图标、一个标题、一句说明、至多一个次操作 |

页头、正文、页脚属于同一个页面，三者的左右内容边缘必须对齐。页头固定或吸顶时，可以使用底部分隔线作为滚动边界，不能同时加阴影和额外卡片背景。

左栏已有一级页签明确表达“对象、图层、调色板”时，不必在正文重复同名大标题；仍需保留页面的可访问名称。

#### L3：区段

| 项目 | 规格 |
|---|---|
| 标题 | `section-title`，13/600；静态标题与折叠标题同级 |
| 内边距 | 横向 0；标题行上下 8，正文不再缩进 |
| 兄弟间距 | 展开内容结束至下一区段顶边 20；连续收起的折叠列表间距为 0 |
| 子级间距 | 标题盒至正文 12；子组之间 12；直接承载字段行时行距 8 |
| 主分隔手段 | 顶部分隔线 `1px solid var(--line-1)`；页面首个区段免顶线 |
| 背景 | 透明，延续页面纸面 |
| 圆角、阴影 | 无 |
| 折叠 | 可选；标题行最小高 40，右侧 16 px chevron，标题与图标间距 8；触屏最小 44 |
| 说明 | 区段说明位于标题之后、字段之前，使用 `help`；与后续内容间距 12 |
| 空状态 | 留在本区段正文，使用简短说明和必要的次操作，不新增空状态卡片 |

顶线位于区段顶边，标题行内部至少保留 8 px 垂直留白。不得再叠加独立的顶部 margin、padding 和 `gap:20px`，重复制造区段间距。

#### L4：子组、子折叠与独立卡片

L4 只有以下三种用途明确的变体。同级、同用途内容必须使用同一种变体。

| 项目 | 普通子组，默认 | 次级折叠 | 独立卡片 |
|---|---|---|---|
| 使用条件 | 需要共同名称或排列的相关字段 | 低频、可选、高级或补充内容 | 独立预览、样例、对象摘要等有明确整体边界的内容 |
| 标题 | `group-title`，12/600 | 同左 | 同左；无必要时省略 |
| 内边距 | 0 | 左侧 12，其余 0 | 12 |
| 兄弟间距 | 12 | 12 | 12 |
| 标题至正文 | 8 | 标题盒后 8 | 8 |
| 子级间距 | 字段行 8 | 字段行 8 | 字段行或内容块 8 |
| 主分隔手段 | 留白 | 左侧 2 px `--line-1` 竖线 | `--surface-raised` 背景色阶 |
| 其他边框 | 无 | 不再加顶部线或外框 | 无装饰性外框；确为可选择对象时，边框可表达交互状态 |
| 圆角 | 0 | 0 | 12 |
| 阴影 | 无 | 无 | 无 |
| 折叠标题 | 不适用 | 最小高 32，垂直 padding 4；左侧 chevron，距标题 8；触屏最小 44 | 卡片整体不再折叠 |
| 说明、空状态 | 放在组内对应内容位置 | 说明位于展开体开头 | 放在卡片正文；不在卡片内部再套空状态卡 |

普通字段组合优先使用留白子组。不能因为字段有三个以上、需要一个标题，或希望“显得重要”，就改成卡片。

L3 顶线与其内部 L4 子折叠的竖线可以共存，因为它们表达不同层级；同一个 L4 不能同时使用竖线、白底卡片和外框。

#### L5：字段行与重复条目

| 项目 | 规格 |
|---|---|
| 标题 | 无分组标题；行名称使用 `label`，只读键名使用 `meta` |
| 内边距 | 表单行默认 0；列表行使用垂直 4、水平 8 |
| 兄弟间距 | 表单行 8；连续列表行 0 |
| 子级间距 | 标签与控件 8；复合控件中的相邻操作 8 |
| 主分隔手段 | 表单使用留白；连续列表使用行分隔线，两者不混用 |
| 背景、圆角 | 表单透明、无圆角；列表默认透明；选中状态沿用 `--accent-soft` 与左侧铜色标记 |
| 阴影 | 无 |
| 折叠 | 不出现新的内容折叠；树节点展开属于列表导航行为，不创建一套属性分组 |
| 说明 | 跟随对应控件下方，不占独立的“说明行标题” |
| 空值 | 显示明确空值或占位文字；不插入空状态卡片 |

列表条目即使包含名称、元信息、状态点和操作按钮，也仍然是一行或一个条目，不因此升级成卡片。

#### L6：字段内部

| 项目 | 规格 |
|---|---|
| 排版 | 标签用 `label`，控件文字用 `control`，值用 `value`，说明用 `help`，状态补充用 `meta` |
| 内边距 | 输入、按钮、选择框复用现有组件；不在字段内部新增容器 padding |
| 相邻间距 | 堆叠标签与控件 4；控件与帮助或错误 4；值与单位 4 |
| 主分隔手段 | 输入组件使用既有描边；纯文字值不额外描边 |
| 背景 | 可编辑输入沿用 `--surface-raised`；代码或特定只读块可用 `--surface-sunken` |
| 圆角 | 控件 8；色块、小标签 4；其他文字节点无圆角 |
| 阴影 | 无装饰性阴影；焦点表现沿用组件规范 |
| 折叠 | 不允许 |
| 错误与说明 | 紧贴控件下方；错误优先于一般帮助，不仅依靠颜色表达 |

### 5.5 间距、字段栅格与页脚

#### 5.5.1 间距按层级逐级不增大

组织间距采用以下序列：

```text
24 → 24 → 20 → 12 → 8 → 8 → 4
```

这是非递增规则，允许相邻层级使用同一档位。它约束内容组织间距，不用于缩小触屏目标，也不要求每层都设置 padding。

| 层级负责的间距 | 标准布局 | 窄布局 | 令牌 |
|---|---:|---:|---|
| L0：浮动任务表面与视口边缘 | 24 | 12 | `--space-6` / `--space-3` |
| L1：并列任务区域 | 24 | 改为单列，区域间 16 | `--space-6` / `--space-4` |
| L2：一级区段之间 | 20 | 16 | `--space-5` / `--space-4` |
| L3：子组之间 | 12 | 12 | `--space-3` |
| L4：字段行之间 | 8 | 8 | `--space-2` |
| L5：标签列与控件列、复合控件之间 | 8 | 8 | `--space-2` |
| L6：标签、帮助、值与单位之间 | 4 | 4 | `--space-1` |

特殊情况：

- 贴边应用壳的几何间距为 0。
- 连续列表、连续收起的折叠标题使用 0 间距，通过行高与分隔线组织。
- 触屏相邻独立按钮保留至少 8 的布局间距；连续列表通过足够的整行点击面积区分。
- 6、10 保留给已有组件内部兼容尺寸，不再作为新增页面、区段或字段组的默认间距。
- 页面左右边距只由页面负责一次。不得出现“侧栏 16 + 正文 16 + 区段 12”的连续缩窄。

#### 5.5.2 标签与控件栅格

字段行依据**可用内容宽度**选择布局，不仅依据浏览器宽度。

| 可用内容宽度 | 标签列 | 控件列 | 列间距 | 布局 |
|---|---:|---|---:|---|
| 小于 280 | 全宽 | 全宽 | 不适用 | 标签在上、控件在下，间距 4 |
| 280–479 | 88 | `minmax(0, 1fr)` | 8 | 双列 |
| 480 及以上 | 120 | `minmax(0, 1fr)` | 8 | 双列 |

执行规则：

- 同一区段使用同一标签列宽，不能按每行文字长度单独决定宽度。
- 标准单行控件在侧栏为 32，在普通工作台和对话框为 36。
- 表单行高由控件及内容决定，最小为对应控件高度；错误和帮助文字使行自然增高。
- 单行标签与控件垂直居中；多行标签与控件顶部对齐。
- 标签允许换行，不能通过 `white-space: nowrap` 挤压控件。
- 某区段的双列布局无法容纳标签或控件时，整个区段切换为堆叠布局，避免相邻行交替使用不同栅格。
- 控件列使用 `min-width: 0`；数值输入、选择框等不能依靠溢出撑宽页面。
- 帮助和错误文字在双列布局下对齐控件列，在堆叠布局下全宽。
- 滑块行的标签与当前值可位于第一行，滑块位于下方全宽；不得把标签、滑块、输入框、单位全部挤在一行。
- 颜色输入使用“色块＋颜色值”的复合字段，组件间距 8；不为两者分别创建卡片。
- 开关行使用一个完整、可点击的标签区域。开关与文案的关系不能只靠左右距离猜测。
- 字段必须有稳定的标签关联；占位文字不能代替标签。

只读键值表使用两列，键名为 12 px `meta`，值为 13 px `value`。长 ID、名称和说明允许换行，不以固定行高裁切。

#### 5.5.3 页脚操作区

页脚属于 L2，不增加新的层级。

| 项目 | 规格 |
|---|---|
| 分隔 | 顶部 1 px `--line-1`，无阴影 |
| 背景 | `--surface-panel` |
| 内边距 | 侧栏为垂直 12、水平 16；宽工作台和对话框为垂直 16、水平 24；窄布局为 12 |
| 操作间距 | 8 |
| 对齐 | 桌面主操作靠末端；状态或次要说明可位于另一端 |
| 控件尺寸 | 侧栏 32；普通操作 36；现有 `.btn--lg` 保持 44，不因层级迁移缩小 |
| 主操作数量 | 当前页面内容与公共页脚合计最多一个 |
| 窄布局 | 容纳不下时整组改为全宽纵排，保持 DOM 顺序与键盘顺序一致 |
| 吸底 | 仅用于需要持续可见的提交操作；不得遮挡最后一行内容或焦点 |
| 内容范围 | 操作、进度、提交状态；复杂参数移入正文区段 |

### 5.6 分组、卡片、折叠与嵌套规则

#### 5.6.1 如何选择容器

| 内容情况 | 应使用的结构 |
|---|---|
| 页面中的一级主题 | L3 区段，标题＋顶部分隔线 |
| 少量相关字段，只需共同排列 | L4 留白子组，标题可省略 |
| 低频、高级、可选或解释性内容 | L3 或 L4 折叠，按所在层级决定规格 |
| 独立预览、样例、可复用对象摘要 | L4 卡片 |
| 连续对象、图层、搜索结果、命令 | L5 列表行 |
| 单个字段及其帮助 | L5 字段行＋L6 内部元素 |
| 简短只读说明 | `body` 或 `help`，无需新增容器 |

折叠的依据是使用频率与任务关系。字段较多但全部属于当前操作的必需项时，不应仅为缩短页面而全部收起。

常用基础项默认展开；高级、更多选项、局部调整等可默认关闭。错误字段、当前操作必需的参数和提交失败原因不得隐藏在关闭的折叠中。

#### 5.6.2 深度上限

- 架构分类最多到 L6。L2 页面内部最多出现 L3 区段和 L4 子组两个分组层级。
- 同一路径最多两层内容折叠：L3 外层＋L4 内层，即只允许一次折叠嵌套。
- L4 下面不得再出现 L4 子组、卡片或新的内容折叠。
- 不允许卡片套卡片。
- 不允许 L5 行内出现新的区段标题、工具栏或多段设置区。
- 不允许通过不断添加小标题、缩进和竖线绕过深度限制。
- 业务对象树的展开深度不等于界面架构深度；树节点保持列表语义，节点详情进入当前属性页。
- 超过深度上限时，优先提升为同级子组；仍然复杂时拆为页面或明确的独立任务表面。

特殊区域现有 actions 内容中，`Advanced` 内包含批量导入等折叠，应在迁移时展平为同级 L4 内容，不能继续嵌套。相关构建位置为 `js/ui/toolbar/special_zones_workbench_controller.js:799`、`:954`。

#### 5.6.3 标题、状态和强调去重

- 一个页面只显示一个主标题。迁入页面的旧卡片标题如果表达同一对象，应隐藏或移除。
- 一个区段最多一个区段标题；眉标不得复述标题。
- 字段名不再重复区段名。例如“透明度”无需写为“河流外观透明度”。
- 页头、状态条、卡片标题中的同一状态只保留最有用的一处。
- 每级局部区域最多一个主按钮；同时，**同一任务表面内，当前可见页面与公共页脚合计最多一个主按钮**。下级区段不获得额外额度。
- 即时生效的属性编辑默认没有主按钮；局部重置、更多、预览等使用次操作。
- 铜色用于当前、选中、主操作及既有焦点指示。普通标题、字段标签、分隔线不染铜色。
- 成功、警告、错误仍使用既有状态色；状态色不用于装饰分组。

#### 5.6.4 折叠与滚动

- 折叠箭头只反映自身展开状态，不能由祖先的 `[open]` 一并驱动。
- 折叠标题支持键盘操作；自定义折叠必须提供对应状态语义。
- 尽量不在折叠触发区内部放置独立按钮。帮助、重置等操作确有必要时，与折叠触发器分开。
- 侧栏页面保持一个主要纵向滚动区域，L3、L4 不再默认创建内部滚动条。
- 工作台允许不同工作列独立滚动，但同一列内不连续嵌套多个滚动容器。
- 搜索结果、菜单、虚拟列表等有明确边界的列表滚动属于限定例外。

### 5.7 对原规范的最小修订

| 原有规则 | 本章补充或修订 | 理由 |
|---|---|---|
| 第 4 章仅描述右栏三级层级 | 改为引用本章七级语义模型；保留页标题 16、一级分组 13、二级分组 12 的主要尺度 | 将已形成的右栏方向扩展到全部界面 |
| 第 2.2 节规定标签 500，第 4 章规定右栏字段 400 | 编辑标签统一为 13/500；正文及只读值使用 400；只读键名为 12/400 | 消除同一角色的规范冲突，同时保持标题 600 的区分 |
| “侧栏内边距 16”没有明确责任节点 | 16 由页面内容层承担，侧栏外壳不再重复添加 | 避免多层 padding 叠加 |
| “每个面板最多一个主按钮”中的面板边界不明确 | 明确为同一任务表面内的当前页面与公共页脚合计一个 | 防止每张子卡片各放一个主按钮 |
| 控件令牌包含 40，而 `.btn--lg` 已为 44 | 保留 `--control-lg:40px` 与一级折叠标题规格；保留已有 `.btn--lg:44px`；粗指针目标最小 44 | 不因规范归并缩小已有交互目标 |
| 所有卡片统一有外框的理解 | 仅有独立整体边界的 L4 内容使用卡片，默认以背景色阶区分，无阴影 | 避免表面、区段、子组重复描边 |

对话框标题由当前实现的 18/700 迁到 22/600、默认 toast 改为浅底，属于落实已有规范与本章角色要求，不构成新增视觉方向。

### 5.8 浮层与特殊表面的统一映射

| 表面 | 层级映射 | 标题与密度 | 表面规格与限制 |
|---|---|---|---|

### 5.9 响应式与触屏

#### 5.9.1 布局档位

| 条件 | L1 表面 | L2–L4 内容 | 标题与字段 |
|---|---|---|---|
| 视口 ≥1280 | 保留双侧栏；大型工作台按既有宽度上限显示 | 侧栏边距 16；宽工作台边距 24；区段间距 20 | 使用标准角色；字段按内容宽度选择栅格 |
| 1024–1279 | 同时只展开一侧栏；工具坞按组换行 | 保持标准内容间距；不能靠缩字号塞入 | 长标题允许换行 |
| 768–1023 | 侧栏为覆盖抽屉，沿用 `min(340px, 88vw)`；独立任务表面距视口边缘至少 12 | 侧栏保持 16；独立工作台进入紧凑布局，边距 12、区段间距 16；列宽不足时改为单列 | 可用内容宽度小于 280 的表单改为堆叠 |
| 小于 768 | 保留默认只看地图；打开的任务抽屉、对话框、工作台使用距视口边缘 12 的可用全宽 | 页边距 12；L3 间距 16；L4 子组纵向全宽排列；不再并列窄卡片 | 标题完整换行；操作容纳不下时全宽纵排 |

补充条件：

- 除视口断点外，独立任务表面可用宽度小于 768 时，内容也进入紧凑模式。
- 工作台多列布局无法满足字段栅格时，按任务顺序堆叠，或使用已有视图切换；不能把整页改成横向滚动。
- 菜单和 tooltip 不自动撑满屏幕，但宽度不得超过可用视口。
- L2 页标题、L3 区段标题、L4 子组标题不得用固定高度裁切，也不默认省略号截断。
- 较长标题换行后，关闭按钮和折叠箭头保持独立点击区域。
- 顶栏保留现有窄屏重排方向，当前 96 px 高度可作为基准；内容需要更多空间时应自然增高。
- 页脚需考虑安全区域，内容区需预留其占用高度。

#### 5.9.2 触屏独立于宽度

`(pointer: coarse)` 对全部视口宽度生效。

- 所有独立按钮、菜单项、折叠标题、色块入口和开关行，实际命中区域至少 44×44。
- 输入、选择框和滑块行最小高度 44。
- 不得只用重叠的透明伪元素扩大命中区域；网格轨道、行高和邻项布局需要同步调整。
- 44 是触屏交互目标下限，现有 `.btn--lg` 也是 44；不是新增的一套内容间距尺度。
- 触屏不通过缩小字号或取消行距来补偿较大的控件。
- 必要说明不得只存在于 hover tooltip 中，应提供可点击帮助或行内说明。

#### 5.10.2 样式所有权

保持既有五层顺序：

- `tokens`：新增排版角色别名、语义间距别名。
- `base`：L0 骨架及全局基础排版。
- `components`：通用页面、区段、子组、字段行等基础规则。
- `panels`：工作台列布局、业务特有的显示结构。
- `overrides`：仅保留迁移兼容规则，迁完一处删除对应覆盖，不继续堆叠。

新结构可以使用一组共享基础类，并与旧业务类并存。不得仅按 `details details` 或 `.card .card` 的 DOM 深度推断层级。

按钮和输入组件目前位于 `overrides`，并承担压住旧面板声明的职责。清除对应旧声明之前，不提前将它们降到 `components`。相关说明见 `css/components/button.css:8`、`css/components/text-input.css:3`。
