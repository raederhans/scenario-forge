# 编辑器 UI 规范（制图台）

2026-10-29 起，编辑器（`/app/`）与落地页（`landing/`）共用一套视觉语言。本文是样式与排版的唯一依据：新增或修改界面时先查这里，规范没有覆盖的情况先补规范再写样式。

## 1. 方向

**制图台**：纸面中性色承载面板，墨色画布承载地图，铜色只用于"当前、选中、主操作"。

- 地图是主角。界面外框用暖灰纸面，地图周围用和落地页同源的墨色，政治色块在深底上最清楚。
- 一个强调色。铜色（`--accent`）表示"你现在在这里 / 这一步最重要"；蓝色只保留给信息提示。
- 密度优先、层级清楚。编辑器是长时间使用的工具：控件 32 px 高、正文 13 px，靠字重和间距分层，不靠边框和阴影堆叠。
- 同一件事只有一种画法。同类控件只有一套样式，同一功能只有一个主入口。

## 2. 设计令牌

所有颜色、间距、圆角、阴影、层级、动效只通过 `css/style.css` 顶部 `:root` 的令牌引用。旧变量名（`--bg-*`、`--text-*`、`--color-accent` 等）保留为新令牌的别名，避免一次性改全部引用。

### 2.1 颜色

| 令牌 | 取值 | 用途 |
|---|---|---|
| `--ink-900` | `#161a19` | 主文字、标题 |
| `--ink-700` | `#3b423f` | 次级标题、强调说明 |
| `--ink-500` | `#5f6662` | 次要文字、标签（在面板底上 ≥ 4.5:1） |
| `--ink-400` | `#8b918d` | 占位符、禁用文字（只用于非必要信息） |
| `--line-1` | `rgba(22, 26, 25, 0.10)` | 默认分隔线、控件描边 |
| `--line-2` | `rgba(22, 26, 25, 0.18)` | 悬停描边、强分隔 |
| `--surface-app` | `#ebe7de` | 应用底色、栏间缝隙 |
| `--surface-panel` | `#f7f5f0` | 侧栏、浮层面板 |
| `--surface-raised` | `#ffffff` | 卡片、输入框、按钮底 |
| `--surface-sunken` | `#efece5` | 分段控件轨道、代码/只读值底 |
| `--surface-canvas` | `#101513` | 地图周围画布（与落地页 `--ink` 同源） |
| `--accent` | `#9c5524` | 主按钮底、选中文字、焦点环（白底上 5.6:1） |
| `--accent-hover` | `#83461c` | 主按钮悬停 |
| `--accent-soft` | `#f4e5d6` | 选中项底色、当前标签底色 |
| `--accent-ring` | `rgba(156, 85, 36, 0.38)` | 聚焦时输入框的 box-shadow 光晕（只作辅助，不单独承担焦点指示） |
| `--info` | `#2f5f8a` | 信息提示、链接 |
| `--success` | `#2f7d57` | 成功状态 |
| `--warning` | `#a66a12` | 警告状态 |
| `--danger` | `#b3402f` | 危险操作文字与描边 |
| `--danger-soft` | `#f8e4df` | 危险操作悬停底 |

规则：
- 面板里不出现 `#hex` / `rgb()` 字面量。确需一次性颜色（地图符号、图例样本）写在对应模块里并注明原因。
- 半透明玻璃面板（`rgba(255,255,255,.9)` + blur）只保留给浮在地图上的控件：上下文条、缩放条、工具坞。侧栏用不透明 `--surface-panel`。

### 2.2 字体与字号

- 界面字体沿用系统字体栈：`--font-ui: "Segoe UI Variable", "Segoe UI", "PingFang SC", "Microsoft YaHei UI", "Noto Sans SC", sans-serif`。编辑器不新增外部字体请求。
- 品牌字体：`--font-brand: "Map Garamond", "Map Noto Serif SC", Georgia, serif`（复用已自托管的地图标注字体，见 `css/map-label-fonts.css`），只用于顶栏字标、对话框大标题、空状态标题，与落地页的衬线标题呼应。
- 等宽：`--font-mono: "Cascadia Mono", Consolas, "SFMono-Regular", monospace`，用于颜色值、ID、坐标。
- 字号沿用五档刻度 `--fs-xs 12 / --fs-sm 13 / --fs-md 14 / --fs-lg 16 / --fs-xl 18`，再加 `--fs-2xl 22`（对话框标题）。
- 字重只用 400 / 500 / 600 / 700。正文 400，控件文字与标签 500，标题 600，数值强调 700。不再使用 650、760、800。
- 行高：正文 1.45，控件 1.2，标题 1.25。中文环境 `:lang(zh)` 正文行高 1.6、不加字距。
- 大小写：按钮与标题一律句式大小写（"Apply color to scope"），不用 Title Case；全大写只用于 `--fs-xs` 的分组眉标，且加 `letter-spacing: .06em`。

### 2.3 间距、尺寸、圆角

- 间距 2 px 细分、4 px 为主：`--space-1 4 / --space-1h 6 / --space-2 8 / --space-2h 10 / --space-3 12 / --space-4 16 / --space-5 20 / --space-6 24 / --space-8 32`。6 和 10 是现有高频值，保留以免大面积改尺寸；新代码优先用 4 的倍数。
- 控件高度：`--control-sm 28`（行内工具、芯片）、`--control-compact 32`（侧栏密集控件）、`--control-md 36`（默认）、`--control-lg 40`（对话框主操作）。`(pointer: coarse)` 下最小 44，且对所有宽度生效。
- 列表行最小高度 32 px，整行可点。
- 圆角：`--radius-xs 4`（色块、标签）、`--radius-sm 8`（按钮、输入框、芯片）、`--radius-md 12`（卡片、弹层、菜单）、`--radius-lg 16`（对话框、浮动工具坞）、`--radius-pill 999px`（只用于开关、计数徽标和浮动圆形把手）。
- 侧栏内边距 `--space-4`，分组之间 `--space-5`，组内控件 `--space-2`。

### 2.4 阴影、层级、动效

- 阴影三档：`--shadow-1`（悬浮控件）、`--shadow-2`（菜单、弹层）、`--shadow-3`（对话框）。侧栏不加阴影，用 `--line-1` 分隔。
- 层级：`--z-map-overlay 10 / --z-dock 20 / --z-sidebar 30 / --z-popover 60 / --z-overlay 100 / --z-dialog 110 / --z-toast 120`。
- 动效：`--dur-enter 140ms`（面板切换淡入）/ `--dur-fast 160ms`（菜单下拉、悬停）/ `--dur-base 260ms`（栏宽折叠），缓动 `--ease: cubic-bezier(.2, 0, 0, 1)`。面板淡入比菜单略快是有意的节奏差，不要合并。
- 状态色用"浅底 + 深字"：toast、提示条、徽标不再用亮色实底配白字。`prefers-reduced-motion: reduce` 下全部过渡降为 0。

## 3. 组件

每类组件只有一套基础类，变体用修饰类。

| 组件 | 基础类 | 变体 | 要点 |
|---|---|---|---|
| 按钮 | `.btn` | `--primary` `--secondary` `--ghost` `--danger` `--icon`，尺寸 `--sm` `--lg` | 主按钮每个面板最多一个；危险按钮默认 ghost 样式（红字），确认态才填充 |
| 图标 | 内联 SVG（JS 里用 `js/ui/ui_icons.js` 的 `createUiIcon` / `setUiIcon`） | 16 / 20 px | 24 viewBox、`stroke-width: 1.6`、`currentColor`。不用 `<` `>` `-` `+` `v` `^` `▾` 等字符当图标 |
| 输入框 / 选择框 | `.field` + `.input` / `.app-select-button` | — | 高 36（侧栏密集区 32），`--surface-raised` 底，`--line-1` 描边，聚焦时 `--accent` 描边 + 外环 |
| 分段控件 / 标签页 | `.segmented` | `--tabs`（下划线式，用于一级标签） | 一级导航用下划线标签；同级筛选用分段控件；不再用胶囊按钮当标签 |
| 折叠分组 | `<details class="disclosure">` | — | 标题行 32 px，右侧 SVG chevron 旋转表示展开 |
| 键值表 | `.kv` | — | 标签 `--fs-xs` `--ink-500` 句式大小写，值 `--fs-sm` `--ink-900`；ID/颜色值用等宽 |
| 列表行 | `.list-row` | `is-selected` | 最小高 32，整行可点，选中为 `--accent-soft` 底 + 左侧 2 px 铜色条 |
| 弹层 / 菜单 | `.popover` / `.menu` | — | `--surface-panel`、`--radius-md`、`--shadow-2`；菜单项 32 px |
| 对话框 | `app_dialog` | — | 焦点陷阱、Esc 关闭、关闭后焦点回到触发按钮 |
| 提示 | `toast` | info / success / warning / danger | 左侧状态色条，不用整块彩色底 |
| 空状态 | `.empty-state` | — | 一句说明 + 一个可选操作，不用虚线框 |

状态：所有可交互元素必须有 hover、`:focus-visible`（2 px 实色 `--accent` outline，对纸面底 ≥ 3:1；不得 `outline: none` 而无替代，半透明色不能作为唯一焦点指示）、disabled（`--ink-400`、不可点）、selected（`--accent-soft` + `--accent` 文字）。

## 4. 壳层排版

```
┌ 顶栏 48px ───────────────────────────────────────────────────────────────┐
│ 字标  项目▾  剧本▾  · 保存状态            撤销 重做 │ 导出  [保存] │ ?  语言  账户 │
├ 左栏 ─────┬──────────────── 地图画布（墨色） ─────────────────┬ 右栏 ──────┤
│ 对象 图层 调色板 │ 上下文面包屑                         缩放条 │ 检查器|图层设置 │
│          │                                                │            │
│          │               工具坞（浮动，单行）              │            │
└──────────┴────────────────────────────────────────────────┴────────────┘
```

- 顶栏：左侧是"你在编辑什么"（字标、项目菜单、剧本菜单、保存状态），右侧是"对它做什么"（导出、保存）和全局工具（帮助、语言、账户）。GitHub 入口移入帮助菜单；Dev 只在开发者模式下出现；顶栏不再放"检查器"开关（右栏折叠柄负责）。
- 左栏一级标签：对象 / 图层 / 调色板。原"素材"标签的指南与参考移入顶栏帮助菜单。
- 上下文条是面包屑：`剧本 › 国家 › 当前地块`，用 `›` 分隔的文字链接；视图模式（Visual Color 等）是独立的小分段控件，不和面包屑混排。
- 折叠柄、缩放、手风琴全部换 SVG 图标。
- 地图画布底色 `--surface-canvas`，与落地页一致。

响应式三档（与 #314 一致，只收敛取值）：
- `≥1280`：两栏常开。
- `1024–1279`：同一时间只展开一侧栏，展开一侧时另一侧自动收起；工具坞放得下就单行，放不下按组折行，不得用横向滚动隐藏控件。
- `<1024`：两栏改为覆盖式抽屉；`<768` 显示一次性提示"编辑功能建议在桌面端使用"（放在地图底部、折叠工具坞上方：项目栏下沿紧挨面板与缩放等地图入口，不能遮挡），关闭后不再出现；默认进入只看地图的布局。

## 5. 文案与双语

- 品牌名 "Scenario Forge" 不翻译。
- 所有可见文案走 `data/i18n/manual_ui.json`；检查器键值标签、状态值（Yes/No、Sea 等）、计数文案都要有中文。
- 计数用完整句式并处理单复数："1 region affected" / "3 regions affected" / "影响 3 个区域"。
- 按钮用动词开头的短句："Apply color"、"Clear override"。

## 6. 验收方式

- 视觉改动：在 1440×900、1024×700 两个视口截图对比，存 `.runtime/browser/uiux-overhaul/`。
- 结构改动：`npm run test:e2e:golden` 必须通过；DOM id 保持不变，被移动的控件保留原 id。
- 令牌迁移：`css/style.css` 中颜色字面量数量单调下降，迁移批次在 PR 描述里给出前后计数。
