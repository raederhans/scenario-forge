# 颜色相似性检查

在编辑器左栏打开 **配色 / Palette → 颜色相似性检查**。展开时检查当前数据；可按国家或图例筛选，选择仅重复、非常相近或相近，结果超过八对时翻页查看。每项显示名称、国家代码（适用时）、颜色值和色块；点击该项定位到国家详情或图例标签，图例定位会自动打开对应页。

检查国家在检查器中的基础配色，以及当前纯色图例的条目。国家列表搜索不会缩小检查范围；定位保留已有搜索条件。隐藏国家、待释放国家、局部地区涂色和特殊区域图案不在范围内。纯色图例本身按颜色去重，因此通常只会出现相近色提示。

相近程度使用三个 RGB 通道的欧式距离，默认阈值为 18；宽一些的阈值为 30。它是人工复核的参考，不是专业色觉或色盲诊断，也不能保证地图上的视觉辨识效果。检查和定位不会自动应用颜色、保存项目或创建历史记录。编辑配色后可点击“重新检查”；打开的面板也会在现有国家/图例界面更新后刷新。

实现位于 `js/ui/palette_color_check_model.js`（纯读取和配对）、`js/ui/palette_color_check.js`（面板）、`js/ui/palette_color_check_editor.js`（与现有编辑器连接）。公共接线仅涉及 `index.html`、`js/ui/sidebar.js` 和图例 owner 的 `focusLegendColor` 接口，适合单独整合。

目标验证：`node --test tests/palette_color_check_model_behavior.test.mjs`。
