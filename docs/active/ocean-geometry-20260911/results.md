# 海洋几何优化结果

2026-09-11，四项推进已完成本地实现、资产更新和源码/静态页面交互验证。未提交、推送或部署。

## 实现

1. **物理海陆与源数据。** 恢复 Natural Earth 中因同名 ID 被跳过的南北大西洋/太平洋部分，海域源简化精度改为 0.005°。使用实际 D3 球面语义转换物理 mask，保留北极帽与日期变更线；NA detail 继承 primary 的全局 land/ocean。
2. **共同几何编译。** 统一平面经纬度边界到 D3 球面边界的转换，按 0.25° 网格加密、共同节点、外环/孔洞绕向及最终 TopoJSON 环引用校正。量化与未量化路径均经过有界格点规范化，修复极小自交和共享边重叠。
3. **一致的绘制、拾取和派生数据。** 最终拓扑实际解码结果作为源导出；TNO 的全部 141 个水域 ID/属性保留，9 个水域分块与源/运行拓扑逐项一致。启动包同步新基础海洋数据。基于 draw order 的遮盖和极区 epsilon 裂缝不作为修复手段。
4. **最终产物验收。** 发布前先检查精确解码 Shapely 有效性，再检查 D3 包含、Equal Earth 填充、物理 mask 排除、同层重叠和边缘偏移；浏览器使用生产投影与 SVG 屏幕矩阵，验证实际点击填色和撤销。

全局细节地图解量化是保留两个不同原点/网格的精确坐标所付出的编码代价。NA detail 从 19,326,019 增至 45,389,418 bytes；不能据此推断具体加载耗时。进一步将 water detail 的 JSON 排版改为已有紧凑 writer，9 个水域 chunk 的解析对象保持完全一致，减少 75,511,492 bytes。
