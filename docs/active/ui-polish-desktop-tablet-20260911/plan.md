# Plan

## Goal
完成用户批准的四轮 UI 优化：桌面优先，兼顾 iPad 类平板，保持现有地图中心布局与视觉风格。展示页同步做小幅优化。

## Scope and stages
1. 修复桌面操作：启动恢复按钮、导出布局、窄画布重要编辑入口。
2. 精修工作区：面板密度、外观导航、颜色库、模式标识、保存/导出入口、字号与状态。
3. 平板：完整窗口横竖屏、侧栏焦点、触控可达的说明、弹窗滚动。
4. 文案与展示：导出基础/高级层级、核心术语、指南、landing、后台可访问性。

## Acceptance criteria
相关目标测试通过；1366/1440/1920 桌面及平板尺寸的核心入口可达，中文导出字段正常排版，关闭抽屉不可聚焦，弹窗 Escape/Tab 保持正常。检查真实 localhost 渲染并记录实际覆盖；真实 iPad Safari 无设备时明确缺口。

## Non-goals
不新增手机支持，不重做风格，不改地图数据/渲染算法，不提交发布或覆盖其他 WIP。

## Risks and constraints
当前有大量地图/渲染 WIP，landing/index.html 也有既有改动；保留。共享 HTML/CSS/toolbar 由主代理独占。dist 仅同步本次相关 UI 产物。
