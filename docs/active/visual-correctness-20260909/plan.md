# 视觉正确性与渲染链路改进

## 目标与计划来源

执行用户指定对话“检查并优化项目”最新一轮 V0–V3 计划：
https://chatgpt.com/c/6aa0b8ff-8bec-83ec-a70c-f01773c7b088
以实际源码和可重放视觉证据为准，退出此前导入与后台恢复专项。

## 阶段与验收

- V0：修复河流 rank 0、城市 opacity 0；实际 owner 入口覆盖零值、普通、缺省、非法；聚焦浏览器检查。
- V1：普通模式缓存与受影响 pass 重绘、状态路径一致性；有限 TNO、HOI4、Modern World 视口；失败记录源码和资产身份、视口、DPR、序列、首个差异 pass、正常/参考/差分。
- V2：依据 V1 实际失败样本收口单个 pass 的输入、写入和复用；删除重复入口，保留未受影响 pass 复用。没有失败证据时不凭猜测改造。
- V3：来源明确的城市命名，城市/交通共同避让，DPR 1/1.25/2 与导出；几何只按真实失败推进。

## 边界

保留历史/架空名称、投影、描边次序、现有有效缓存；不机械替换数值 fallback，不新建视觉监督器，不录制未审查 golden，不扩大 allowlist 或刷新冻结基线。共享 renderer 主壳、pass 注册、合成由主代理独占。仅本地改进与验证，不包含生产发布。
