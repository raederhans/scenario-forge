# 西班牙与塞浦路斯细化结果

## 改动与来源

本轮聚焦西班牙方向的巴利阿里群岛及塞浦路斯。改动发生在离线来源配准与岛体生成；继续使用现有 ATLISL、场景海岸线、粗/细分块和交互路径，没有新增运行时依赖、缓存或分块架构。

巴利阿里改为三组独立原岛锚点：7114 → ES531（伊维萨/福门特拉）、9793 → ES532（马略卡）、9845 → ES533（梅诺卡）。各组先将原始 HGO 岛体配准到完整的运行时原岛，再对该组填海省份使用同一组系数。原有群岛筛选遗漏了梅诺卡对应的完整原岛；现在三组原岛覆盖率均不低于 99.9%，最终保持三个独立部件。三个没有原岛锚点的伊维萨来源碎块记录在诊断中，暂未纳入。

塞浦路斯原岛来源为 7193、11984、13332、13333、14138、17019；六个填海州 8551–8556 共用原岛配准系数。原岛和填海轮廓直接与 CY000 合并，不用额外膨胀或整体填孔。最终原岛覆盖率不低于 99.9%，一个连续 Polygon，内孔为零。

最后两个内孔的根因是遗漏 `14138 / state 2656 Template_State`。主代理把候选内孔逆变换回 HGO 栅格，对相交像素逐格核验：两孔均 100% 落在该陆地省份。补入该省份不改变原岛包围盒或配准系数，最终只增加两孔对应的约 0.001060402 平方度，没有向外围扩张。先前只与已选省份比较的探针不足以判断孔洞是否是源水面；最终结论以位图检查为准。

巴利阿里仍为 IBR，塞浦路斯仍为 TUR，交互 ID 不变。并行任务更新的国家名称和手工来源已保留；几何检查也验证了非 ATL 政治数据、名称及手工映射的一致性。

## 性能证据

冻结同一应用，先对本轮基线及 candidate-v1 测量；每组含三个独立浏览器上下文启动、六次平移、六次缩放及一次填色/撤销。每次交互前要求实际任务稳定一秒，反馈必须同时有状态改变、真实绘制计数推进和目标附近复合像素改变。初次基线因 ROI 未跟随缩放后目标而失败，修正的是测试观察位置，未改产品超时或准入条件；失败记录单独保留。

| 指标 | 基线 | candidate-v1 |
|---|---:|---:|
| 平移 p50 / p95（ms） | 19.4 / 27.2 | 23.5 / 28.1 |
| 缩放 p50 / p95（ms） | 23.8 / 26.7 | 17.5 / 24.1 |
| 单次填色 / 撤销（ms） | 93.4 / 362.4 | 94.8 / 396.1 |
| 三次 TNO ready（ms） | 7104.5 / 6939.5 / 7209.6 | 6868.8 / 6901.7 / 6366.5 |

这些是小样本本机数据，不构成统计显著的加速结论。最终 candidate-v2 另行复测，包含后续合入的国家名称；其数字用于最终数据的运行确认，不把跨批次启动波动全部归因于几何变更。

最终 candidate-v2 的同一固定马略卡目标复测全部通过（14 次交互）：平移 p50/p95 为 27.6/30.0 ms，缩放为 26.6/32.7 ms；单次填色 120.3 ms、撤销 544.2 ms；三次 TNO ready 为 8002.9、7898.0、7530.8 ms。撤销与启动比前一批慢，当前样本不能分离几何、名称内容与时段/机器波动的影响；不声称完全零开销。现有数据显示常用平移缩放仍在几十毫秒，数据增量很小，没有证据要求修改运行时架构。

## 验证与交付

最终 candidate-v2 已通过：12 个配准/岛组目标测试、3 个真实候选数据测试、严格场景发布契约、源数据/粗细分块一致性及非 ATL 保留检查、现有海岸线准入门槛。两处遗漏陆地同时加入数据覆盖与运行时 land/coast/not-sea 回归断言。

全局水域验证仍失败在三个原有英国探针：Swansea Bay、Humber Estuary、Cardigan Bay。最终与基线的 water_regions.geojson 字节一致，失败集合一致，其余检查（含地中海覆盖）通过。未修改验证门槛或放宽 allowlist。

本地规范数据和 dist 已同步，本阶段共涉及 26 个场景文件及对应的 26 个 dist 场景路径，实际 dist manifest 已刷新。所有写入先核对当前文件与保存基线一致；并行的国家名称改动经过三方合并保留，七个无内容变化的 dist 文件保留原换行字节。没有提交、推送或部署。

实际 dist 的聚焦浏览器测试通过（25.7 秒，合计 27.9 秒）：验证目标归属与索引、两处缺口及新增岸地均在陆地/海岸面且不在海域、被淹没旧海岸不残留，以及可见性切换后的海岸缓存更新。此前 candidate-v1 冻结包与实际 dist 也分别通过同一基础检查。

数据目录重建为 663 项，data_health 无错误、10 项大文件告警。目录测试 17/18 通过；唯一失败仍是前一阶段已确认的 landing 英文文案与测试期望不一致，未修改无关页面或扩大测试容许范围。
