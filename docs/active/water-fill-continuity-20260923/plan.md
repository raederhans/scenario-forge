# 湖泊填色连续性与海水联动

用户授权修复湖泊缩放、平移后丢色，检查整个北欧湖区，并在验证后推送、合并。

1. 修复水域图片复用与视野覆盖判断，保留投影路径缓存。
2. 让 Atlantropa 海水语义跟随 ocean fill，保留陆地、盐滩和浅滩色。
3. 用现有 Natural Earth 湖泊源补齐主要北欧湖与 TNO 克隆清单；保留场景特有水域和非水几何。用户确认仅接入较大湖泊，不批量补小湖。
4. 运行行为测试、湖位像素检查、水域数据契约与 Pages 构建，PR 检查通过后合并。

验收：湖泊移出/移入及缩放后稳定填色；Nordic 样点有独立水面；Atlantropa 改色联动；生成入口一致；非水几何不变。

边界：不改变政治归属，不扩大启动 shell 加载，不修改未归属 `.playwright-mcp/`，不绕过分支保护。
