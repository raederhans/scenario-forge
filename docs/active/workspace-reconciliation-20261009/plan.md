# 工作区同步与遗留改动处理

用户授权逐项检查未提交、未推送及未同步改动，并适当清理、合并 worktree 和分支。

1. 对主目录、15 个关联工作树、37 个本地分支、28 个远端分支及 64 个历史 stash 核对内容、提交归属和恢复路径。
2. 完整保存混合 WIP、原索引、Git 元数据及 ignored 证据；精确覆盖或已关闭探针的旧分支归档后清理。
3. 将主目录快进到已交付主线，从剩余内容中提取仍有价值的改动，按当前契约验证后独立提交。
4. 通过正常 PR 检查交付，分别记录本地验证、推送、合并和发布状态。

验收要求：不重放过期整文件，不删除未归属数据；每个清理项有恢复引用及归档位置；主目录同步状态明确；新增修复由目标行为测试和相应数据契约证明。历史 stash 保留，不将其数量当作仍待交付的功能数量。
