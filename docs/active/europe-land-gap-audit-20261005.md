- v2 有 11 个 overlap 测量副本坍缩，没有 gap 测量副本坍缩。坍缩项保留原始 deg² 面积、bounds 和几何，累计面积 0 只是未解析测量的占位，宽度 `null` 表示未测得；相邻边界不一致诊断没有因此删除。
- 封闭缺口仍须检查源数据中的真实内陆水域；“不是窗口/蒙版边界”不等于“应当分给某个国家”。`cntr_code` 仅作为 runtime 原始标签分组，不是稳定来源国身份，也不代表 TNO 归属方。

### 两个 SK/UA 缺口的来源边界

本轮核对源 `geoBoundaries-SVK-ADM2.geojson` 与 `geoBoundaries-UKR-ADM2.geojson`：允许恢复的区域来自 SK 同 ID 来源交集，UA 来源对这两处几乎没有面积支持。旧报告中的每洞来源交集面积尚未按 v2 重算，本文不沿用其精确 km² 数字。两洞均不接触 allowed-land 边界。

## 已实施的审计完善

`tools/audit_tno_east_europe_gaps.py` 保留原 API 和几何差集，新增独立分诊字段：窗口截断、真实表面边界线接触、封闭政治面缺口、helper 触点，以及 raw `cntr_code` 标签、稳定来源身份与归属方的明确区分。表面边界接触只用于诊断，不移动、buffer 或吸附几何。helper 识别与 renderer 的显式 kind、Arctic ID、旧名称规则一致。

回归覆盖封闭洞、海岸/水边界、点接触与浮点短线、辅助层、新旧属性兼容、LOD 对照和真实 UA/BY 样本。新增定点修复工具只允许显式审查的两洞、既有 ID/归属和同 ID 来源交集，拒绝无来源的全洞分配。

测量另作 v2 修正：直线经纬度边在测量副本中按 0.001° 加密后，再投影到以 bbox 中心确定的局部 LAEA；面积与宽度均使用该副本，代表点仍取原始几何。旧方法直接投影原顶点，对长窄面会依赖共线顶点数量和来源分段方式，不能将此前 km² 数字全部当作精确面积。真实长窄样本与合成回归在 0.001°/0.0005° 下收敛，分段面积守恒；原始 topology、差集、输出几何和候选字节未修改。空测量副本明确标记为 collapsed，不调用 MIC；其余 GEOS 异常继续失败。

## 后续批次与验收

1. **先修复 LOD 公共边界生成路径**：当前独立简化不能保证相邻地块或不同 detail chunk 的混用覆盖。以本次完整边界失败样本为回归基线，验证有界的粗层增补或共享边界简化；需同时保留已有合法覆盖，避免新增重叠、无效面或将缺口推到窗口外。不能靠持续追加 precision IDs 规避这个问题。
2. **再分批修公共边界**：按 CZ–PL–DE、AT–CZ–SK、PL–SK、UA–BY/MD 分批，核对同 ID 原来源可恢复区域；没有来源支持的走人工审查公共边界。旧历史裁切和剧本所有权不可被现代国界覆盖。
3. **精度升级随后**：HU/RO/BG 的低坐标密度最明显。先准备同 ID 候选，再与相邻国联合验证，不能逐国替换后只验各自有效性。
4. **每批发布前**：同时验证原领土保留、无实质新增重叠、保护水域不变、剩余缺口清单、完整边界混合 coarse/detail、点击/上色/撤销；重建受影响 chunks、startup、gzip 和 snapshot。局部通过不能写成全欧洲无缝。
