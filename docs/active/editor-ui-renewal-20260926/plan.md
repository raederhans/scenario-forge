# 编辑器 UI 四阶段改版

## 目标与范围

依据 2026-09-26 用户批准的 `.runtime/reports/generated/ui-audit-20260926.md`，依次完成：

1. 修复项目导航/战略工具耦合、语言刷新、重复空状态、不可用表单和中文排版。
2. 完成城市图层到右侧属性与稳定底栏的可运行样板。
3. 将对象、图层、配色、素材归入左侧；当前属性归入右侧；项目操作归入顶部。
4. 统一底栏、交通等工作台与双语/尺寸/键盘验收。

## 验收

- 项目导航不改变当前编辑模式；战略工具需明确进入。
- 双语切换刷新动态选项、列表、计数与账号，保留选择和过滤。
- 空状态只有一个有效前置动作，不支持能力不展示整屏禁用参数。
- 城市、边界、海洋等属性可通过图层入口访问；原有 ID、状态、事件、历史与保存契约保留。
- 1366×768、1440×900、1920×1080 与紧凑视口的主要动作可触达，中文不拆短词；真实地图和 UI shell 分别验证其声明。
- 只运行对应风险的目标测试和浏览器检查；不把旧测试中旧布局断言当作新布局需求。

## 非目标及约束

不发布、不推送、不重做地图渲染或数据；保留开始时 22 个已修改文件及未跟踪文件。主代理统一拥有 index.html、css/style.css、sidebar.js、toolbar.js、启动整合、新工作区布局控制器。子代理与 CLI 仅写分配文件。现有业务 owner 和原生 select 的 input/change 契约复用。
