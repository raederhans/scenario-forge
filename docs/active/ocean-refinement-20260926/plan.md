# 普通海域细化

范围：将已有普通海区来源共享给基础地图，补入有公开多边形的东南亚与加勒比入口海域，增加有来源的外洋分区。排除湖泊、水深、地中海、Atlantropa、政治几何和发布。

1. 复用未经过场景裁切的 Marine Regions 来源，保留旧 ID，按基础物理海陆遮罩重建；成熟子海区推广到普通地图。
2. 接入 SeaVoX 缺失命名海域；基础与 TNO 分别裁切并保留来源、层级和中英文名称。
3. 基础地图增加大西洋/太平洋八个 SeaVoX 外洋区；保留旧父区剩余面及旧 ID。TNO 原 20 区继续兼容，不随意重划既有填色范围。
4. 子区继承父区自定义颜色，显式子区颜色优先。检验旧 ID、所有非水对象、地中海原几何、来源/运行时/分块一致、无重叠、极区/日期线、真实填色和撤销。
