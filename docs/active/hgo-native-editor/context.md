### Native dataset v1

`assets/default/manifest.json`: `{format:'hgo-native-dataset',schemaVersion:1,id:'hgo-1936',revision,coordinateSpace:{kind:'pixel',width,height,origin:'top-left',wrapX:false},assets:{ids,core,places},source,stats}`.

Asset entries: `{url,encoding,byteLength,sha256,decodedByteLength?}`. URLs are relative to the manifest; encoding is `gzip` for ID bytes, `json` for metadata. sha256 identifies transported bytes. IDs are row-major top-down uint16 little-endian. Code 0 is nodata. Other codes index `core.provinceIds` and `core.provinceStateIds`; index 0 in both tables is null. Source province ID 0, if defined, receives its own nonzero code and is not conflated with nodata.

`core.json`: `{schemaVersion:1,provinceIds:[null,...],provinceStateIds:[null,...],states:[{id,name,nameKey,entityTag,controllerTag,coreTags,category,provinceIds,bounds:[x0,y0,x1,y1],anchor:[x,y],pixelCount}],entities:[{tag,name,color,kind,anchor,bounds}]}`. Stable state IDs are numeric in metadata and string keys in documents. Names resolve from native localization, otherwise source nameKey/tag. `kind:'water'` is explicit for WTR; other tags remain reference entities. An anchor must be an actual member pixel center, not a centroid outside its region. Province ID/state index tables preserve original source identifiers; no ISO assumptions.

`places.json`: `{schemaVersion:1,places:[{id,name,provinceId,stateId,entityTag,x,y,importance,isCapital}]}`. Only source-grounded victory-point/capital information. A capital flag requires defensible native source evidence; no invented modern coordinates. Empty places is valid for fixtures. The data builder owns the exact source provenance and deterministic revision rule and communicates any needed contract change before writing consumers.
