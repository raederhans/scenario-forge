“封闭政治面缺口”是几何分诊，仍需来源和水域核对。边界差异可能来自海岸、内陆水域、掩膜或政治面轮廓；窗口截断项不作为闭合修复候选。原始 `cntr_code` 混合了现代国家代码、剧本标签等含义，不能替代稳定 ID、来源血缘或 `owners.by_feature.json`。

测量 v2 先对测量副本按最长 0.001° 加密直线经纬度边，再转入以各几何 bounds 中心为原点的 LAEA。原始差集几何、浏览器探针和源交集不变。宽度是最大内接圆直径，不是整条缝的平均宽度。原方法直接投影稀疏顶点，会让长窄面面积随共线顶点分段而改变；叙利亚沙漠样本由旧值 84.70 修正为 **172.42 km²**。0.0005° 步长复核以及共线分段/分区回归支持当前测量稳定性，不能把这个变化误报为数据新增了缺口。

对于约 7.73e-17 deg² 的真实重叠样本，加密测量副本会坍缩为空面。工具现在显式记录 `measurement_collapsed`、原始平方度面积、bounds 和可选几何；面积 0 只是未解析累计占位，宽度 `null` 表示未测得。相邻边界诊断与阈值以下的坍缩 gap 单独保留，其他 GEOS 异常继续失败。

### 巴尔干：来源支持存在，稳定 ID 分配尚未建立

波黑—黑山—塞尔维亚交界的候选接触 `BA_ADM1_54001226B66267900922909`、三个 `ME_ADM1_MNE-*` ID 和 `RS211`。本地 Natural Earth 的 BIH/MNE/SRB 共 64 个有效 ADM1 面联集覆盖该缺口，探针落在来源 `BIH-4807`（Foča）。本地 1,355 个有效湖泊面与该缺口没有面积交集；河流尚未独立核对。

这支持继续调查陆地遗漏，但不能直接把整洞分给波黑。当前 BA 地块与 Natural Earth ADM1 的来源血缘不同，所需同 ID 的 BIH geoBoundaries 原始缓存尚缺失。应先恢复可追溯来源及对应关系，再建立固定 ID 的候选。Natural Earth 文件名的 `10m` 指 **1:10,000,000 比例尺**，不表示 10 米精度。

### 小亚细亚：高细节来源已经在本地，尚未证明完整接入

阿勒颇以北的 223.55 km² 缺口接触 `SYR-137`、`TR631`、`TRC11`、`TRC13`，现有剧本 owner 均为 `TUR`。TUR+SYR Natural Earth ADM1 联集覆盖该缺口，但同 ID 的 TR NUTS 来源只支持其中约 **10.24% 的原始平面面积**，剩余部分仍缺少可靠的现有 ID 分配依据。

本地已有 GISCO 2021 NUTS level 3 的 1:1,000,000 来源：81 个 TR feature、16,013 个坐标；当前 runtime 的原始 `cntr_code=TR` 组同为 81 个 feature、2,725 个坐标。`data/europe_test_nuts3.geojson` 的 TR 组为 2,846 个坐标，不能当作这份较高细节来源的等价替代。顶层精度来源声明不含 TR/TUR。坐标数反映几何复杂度，不是准确性认证；原始 `TUR` 标签的其他九个面也不能当成现代土耳其的完整清单。

因此下一步应联合审查 NUTS 与旧 SYR 来源的公共边界及 TNO 历史裁切，不能只替换土耳其内部轮廓。来源文件存在、候选通过和线上采用需要分别核实。

## 修复顺序与验收条件

1. **先解决公共边界的混合 LOD 生成问题。** 上一轮 SK/UA 的同 ID 恢复候选已经表明：精确面替换粗面后，邻居曾由粗层外扩补偿的欠覆盖会重新露出。须在完整 feature 边界及邻接 chunk 组合上验证，不能只看小窗口或无限追加 precision IDs。
2. **优先做黎凡特的两处同 ID 候选。** 固定来源与现有 ID/owner，恢复来源支持部分，排除真实水域，并检查原领土保留、新增重叠、邻接和所有受影响 coarse/detail 组合；当前来源分区证据不替代这些验收。
3. **巴尔干与小亚细亚先补来源及公共边界依据。** 巴尔干需要可靠的旧 ID 对应关系；小亚细亚需要 NUTS 与 SYR 旧面联合处理。南欧窗口内 ES/PT/IT 有精度来源声明，多个巴尔干来源组仍很稀疏，不能据此认为前者无缝或后者可以整体覆盖。
4. **水域/海岸单独修复定义。** 将死海、黑海等来源支持不足或真实水体相交项从政治面补洞队列中分离；保护 Atlantropa 和场景历史岸线。候选通过后才重建 chunks/startup/gzip/snapshot 并验证点击、上色、撤销。
