- 从已有俄罗斯 ADM2 源恢复七个极北行政区，清除遗留约 73°N 裁切。泰梅尔北界从 72.997°N 恢复至 81.262°N（包括所属岛屿）。修复按物理陆地掩膜限制，并保留现有南部形状。

- 水域精度检查修复博斯普鲁斯海峡微小碎片；其他 165 个水域要素未改变。
- 修复启动包 gzip 更新晚于构建快照造成的指纹失配，重建时先同步压缩包再计算快照。
