# Showcase images

The README and landing page share the same product images under `landing/assets/`.

- `product-workspace.webp`: captured on 2026-09-23 from the current local editor at `/app/`, using the TNO 1962 scenario. The native 3200 × 1800 lossless WebP capture (1600 × 900 viewport at DPR 2) shows a European viewport at 480% zoom, with the right inspector collapsed. Presentation settings: ocean `#203856` at full opacity, matching the scenario sea; coastal accent off, rivers off, city marker scale 0.45, density 0.35, sparse labels, and capital emphasis off. The camera was positioned with editor pan/zoom, and capture waited for the map passes to settle. Appearance was adjusted in the local editor; map geometry and political ownership were not retouched. This is a styled workspace capture, not the default sample export.
- `work-alt-history-med.*`, `work-scenario-switch-europe.*`, and `work-atlas-japan-corridor.*`: generated overview maps. The site and README display their SVG originals to preserve lines and type at any screen density. Rebuild SVG and source metadata with `npm run build:landing-work-maps`; raster targets remain defined in `tools/rasterize_landing_assets.py`. Their JSON companions record source paths, projection, bounds, and selection policies. They accompany starter projects rather than promising pixel-identical default exports.
- The Mediterranean map resolves stable `properties.id` values against the TNO owner table and uses the scenario country colours. Non-geographic helper features are excluded. All 724 Atlantropa water, land, and shoal features participate; a shared sea colour removes artificial tile outlines. The current extent contains 30 scenario owners.
- `japan-preview-*.svg`: national views generated by `tools/build_landing_japan_preview.py`, using the project carrier projection and source road, rail, station, and city data. Each view has its own legend and source city labels. The site uses SVG; WebP fallbacks are 2040 × 1320.
- `hero-blank.svg` shows neutral administrative subdivisions. `hero-hoi4-1936.svg`, `hero-hoi4-1939.svg`, and `hero-tno-1962.svg` use the same Europe/Mediterranean frame for both the scenario gallery and the political-state comparison. Country borders keep the shared source geometry; the TNO view includes the scenario Atlantropa layers. Rebuild with `tools/build_landing_europe_1936_showcase.py`.
- Road and rail previews retain every eligible source path within the selected extent, including path endpoints. Line hierarchy controls visual density; route-count truncation is not used. Coverage remains limited to the checked-in transport sources and their scale.
- `export-workbench.webp`: a native 3200 × 1800 screenshot of the actual local export workbench with the TNO 1962 scenario, composite PNG target and 2× resolution selected. The preview is ready and the controls are part of the working editor. It illustrates the export workflow, rather than another finished-map example.
- The landing source tree is accessible HTML, with separate linked records for geography, scenario ownership, transport and geographic context. The files-and-sources view pairs each scenario map and the Central Japan atlas with its SVG, editable project, and source record.
- `social-preview.svg` and `social-preview.png`: the link-preview artwork, using the same workspace capture and landing typography/colors.

HOI4 and TNO illustrations represent their game settings, including alternate-history geography. Generated previews simplify presentation, not source ownership. Geographic assets retain their dataset terms; consult the JSON companions and `data/source_ledger.json`.

Early `hero-workspace.webp` and `shot-*.webp` files in this directory are retired from the README, retained only to avoid breaking historical references. Do not use them for new product material.
