Good to know.

Do I need to install anything?

No. Both editors run in a modern browser, and your projects are saved as files on your own computer.

How are the two editors different?

Scenario Forge edits vector political maps across five starting worlds, with everything above. HGO Atlas edits one mod's native pixel map, state by state. Each has its own project files.

Can I share the maps I make?

Yes. The code is MIT-licensed; map data comes from sources such as Natural Earth, geoBoundaries and OpenStreetMap, which keep their own terms. See all data sources
